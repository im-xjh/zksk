# 口碑周报（6.19-6.26）配图生成 Prompt

## 通用设定

- **画幅**：横向 3:2
- **风格**：模仿我上传的参考图风格（漫画/插画风格）
- **文字**：每张图配一句短文案，以漫画标题字的形式嵌入画面，位置和大小由构图决定，不遮挡核心主体
- ——以下每条 prompt 我会附上事件背景资料，请结合背景理解场景——

## 事件一：王石遭规模化网暴报案

**画面文字**：谣言，正在杀死企业家

**场景描述**：
一位西装中年企业家的背影，站在落地窗前俯瞰城市天际线。窗外天色阴沉，玻璃上倒映出密密麻麻的匿名账号头像和破碎的点赞图标，如数字风暴袭来。企业家的身姿挺拔但不免透出孤绝感。画面左侧光线偏暗，右侧有一线微光透入。

**画面文字**：把“除菌”变成了“除人”

**场景描述**：
一瓶消毒液立在画面中央，瓶身标签上印着变形的天平——一侧压着“流量”，一侧压着“价值观”，天平明显向流量一侧倾斜。背景是被撕破的海报墙，碎片上隐约可见男女对立的人物剪影。色调以灰蓝为主，消毒液的绿色在画面中显得突兀而不和谐。

## 事件三：1点点奶茶食安问题

**画面文字**：前场光鲜，后场失控

**场景描述**：
一家街角奶茶店的剖面视角，仿佛被切开展示内部。前场灯光明亮、顾客排队购买，后场操作间昏暗杂乱——效期标签被涂改、食材裸露、蚊香盘搁在操作台上。前后场的强烈对比形成视觉冲击。整体色调冷暖对冲，前暖后冷。
