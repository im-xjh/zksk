# 京宣参阅消息选题和简报文件组织SOP

## 一、本SOP的定位

本SOP规定"京宣参阅消息"的选题和简报文件怎么命名、文件内怎么分节、版本怎么迭代、旧文件怎么归档，以及写作时应该参考哪份文档。

它只负责文件层面的格式与组织，不管怎么写内容。选题怎么判断主体、从什么角度写、为什么值得报送，参见《选题和简报写作思路》；选题的文字篇幅、语言和改稿规范，参见《选题写作纠偏记录》；客户硬规则、完整简报范文和报送情况，参见 `guide.md`；选题的发现、核验、筛选流程，参见《选题搜集SOP》。

本SOP若与 `guide.md` 或用户当次要求不一致，以 `guide.md` 和用户当次要求为准。

## 二、文件命名

1. **每日素材文件**：`8.X素材.md`，如 `8.6素材.md`。汇集当日各主题的原始材料，文件内用 `# 主题` 分节，每节下列来源链接、正文内容和评论等。
2. **每个主题一个文件**：`8.X：主题.md`，如 `8.6：境外反华账号炒作北京警方凌晨查手机视频攻击执法形象.md`。
   - 日期用点号格式（`7.29`、`8.3`、`8.6`），不写"月日"，不带前导零；冒号为全角。
   - 文件名不出现"参阅消息选题""参阅信息""观察"等字样，选题和简报的区分放在文件内。
   - 主题标题：选题被选中写成简报后，以简报标题为准；只有选题时，用选题的主题。
3. 所有文件放在 `京宣参阅消息/` 根目录。版本标识不放进文件名，一律用文件内的【v1】【v2】标注。

## 三、文件类型与目录

| 类型 | 示例 | 作用 |
| --- | --- | --- |
| 每日素材文件 | `8.6素材.md` | 汇集当日各主题原始材料 |
| 主题文件 | `8.6：主题.md` | 每个主题一个，内含选题和（如有）简报 |
| 存档文件夹 | `存档/` | 存放被合并、被替换的旧文件，不删除 |
| 规则与说明文档 | `guide.md`、《选题和简报写作思路》《选题写作纠偏记录》《选题搜集SOP》 | 规则、范文、流程与写作参考 |

素材文件与选题/简报是两类内容：素材是采集来的原始材料，选题/简报是加工后的产出。整理其中一类时不动另一类。

## 四、主题文件基本框架

每个主题文件内用两个三号标题分节：

```markdown
### 选题

【v1】

（选题内容：一段话交代事件主体、讲述者和报送理由，附来源链接）

### 简报

【v1】

【8月X日参阅信息：简报标题】
（简报全文：事件事实、舆论观点、分析建议，附来源链接）
```

规则：

1. 文件必有 `### 选题` 节；`### 简报` 节只在选题被选中报送后出现。选题没被选中，文件只有 `### 选题`。
2. 选题选中写成简报后，简报为主，选题内容保留在 `### 选题` 节附后，不删除。
3. 选题文字按《选题写作纠偏记录》控制篇幅和语言；简报全文按 `guide.md` 的 example 范文组织。

## 五、版本迭代与归档

**核心规则：不覆盖已有内容，而是新建版本。这条对选题和简报都适用。**

1. 修改或重写选题、简报时，不在原文字上改，而是在对应节下另起一个版本。原有版本保留不动。
2. 同一主题的不同版本放在**同一文件的同一节**下，用【v1】【v2】【v3】… 依次标注。选题的不同版本放 `### 选题` 节，简报的不同版本放 `### 简报` 节。只有选题时，`### 选题` 节同样按【v1】【v2】追加版本。
3. 同一主题拆成多个旧文件（如选题和简报分属两个文件、同一主题有多个选题文件）需要合并时，合并成一个主题文件；被合并的原文件移入 `存档/`，不删除、不替换。
4. `存档/` 是历史文件的唯一归宿，不做清理性删除，除非用户明确要求。

典型流程：发现线索 → 写入当日素材文件 → 写成选题，落在主题文件的 `### 选题` 节 → 选题被选中 → 在 `### 简报` 节补写简报 → 若同一主题此前有分散的旧文件，合并后旧文件移入 `存档/`。

## 六、写作时参考什么

| 场景 | 参考文档 | 内容 |
| --- | --- | --- |
| 文件命名、分节、版本、归档 | 本文档 | 文件层面的格式 |
| 选题文字篇幅、语言、改稿规范 | 《选题写作纠偏记录》 | 选题怎么写得像快报、不AI味 |
| 选题角度、主体判断、为什么报送 | 《选题和简报写作思路》 | 写作内容与构思 |
| 客户硬规则、完整简报范文、报送情况 | `guide.md` | 上位依据、文风样例、采用倾向 |
| 选题发现、核验、筛选、出池 | 《选题搜集SOP》 | 选题流程 |

写作选题时，依次参考：本文档（文件怎么放）→《选题写作纠偏记录》（文字格式）→《选题和简报写作思路》（内容角度）→ `guide.md`（规则与语感）。

写作简报时，依次参考：本文档（文件怎么放）→ `guide.md` 的 example（完整范文）→《选题和简报写作思路》（结构逻辑与案例）。

## 七、与《选题和简报写作思路》的分工

《选题和简报写作思路》开篇即说明：它不提供固定模板，也不规定篇幅、文风和操作流程，"这些内容分别由其他文档承担"。它只回答"为什么选、从什么角度写、为什么值得报送"。

本文档补上它没有覆盖的部分：

- 文件怎么命名、放在哪（第二节）。
- 文件内怎么分节、简报何时存在（第四节）。
- 版本怎么迭代、旧文件怎么归档（第五节）。

两者关系：写作思路决定"写什么、内容怎么写"，本文档决定"写出来放在哪个文件、怎么组织"。写作时两份文档结合使用，缺一不可。
