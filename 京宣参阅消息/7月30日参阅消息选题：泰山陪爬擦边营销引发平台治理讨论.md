开小红书，满屏都是“泰山陪爬，八块腹肌体育生”“夜爬陪登，情绪价值拉满”。标价600到1000块，服务清单写得漂亮：背包、探路、拍照、递水，甚至还有“公主抱”。

评论区一半在尖叫“好帅”，一半在质疑——这到底是陪爬山，还是花钱买人？

Image
2025年，一名26岁小伙陪爬泰山年入30万元的消息，把这个行业推上了风口浪尖。

不少人看到新闻后的第一反应是：陪别人爬几趟山，一年就能赚几十万元，这钱未免也太好挣了。

Image
可真正干过陪爬的人都知道，这根本不是什么轻松活，一趟泰山走下来，少则几个小时，多则十几个小时，遇到体力差的游客，还要一路搀扶。

问题在于，这些真正体现专业性的东西不好拍，也不够刺激，相比之下，一张腹肌照、一段公主抱视频、一句“姐姐别怕，我保护你”，十几秒就能引来大量围观。

Image
于是，陪爬者开始给自己贴上各种吸引眼球的标签：“体育生”“退伍小哥”“八块腹肌”“高颜值男大”“情绪价值拉满”。

有些广告里，路线经验和安全能力只占几行，照片和身材介绍反而占了大半。

Image
消费者的关注点也跟着变了。有人上来就问：“能不能穿背心？”“有没有腹肌照？”“累了可以背吗？”“公主抱算不算在费用里？”

这哪里像是在找一个熟悉路线的陪爬者，更像是在挑选一个临时陪伴对象，正常的情绪价值，是游客累得走不动时，有人耐心陪着，是夜爬害怕时，有人提醒路况。

Image
可现在，一些人把“情绪价值”理解成了甜言蜜语、亲密互动和肢体接触，这四个字听起来很温柔，却也成了陪爬行业里最模糊的一块遮羞布。

只要打着“提供情绪价值”的名义，牵手、搂肩、背人、公主抱，似乎都能被包装成正常服务，更离谱的是，网络上的陪爬视频，桥段几乎一模一样。

游客刚说累，陪爬小哥立刻蹲下；走到陡坡，对方顺势牵手；遇到台阶，直接来一个公主抱。配上音乐和滤镜，看起来既浪漫又贴心。

Image
可镜头里的温柔，不一定等于现实中的服务，有游客花了八九百元找一对一陪爬，原以为对方会帮忙背包、控制速度。

结果见面后，对方全程冷着脸，游客稍微休息一会儿就开始催促。想让对方帮忙提一下包，却被一句“没有这项服务”直接拒绝。

宣传视频里是“姐姐我保护你”，真正付钱以后，却可能变成“赶紧走，别耽误时间”，消费者花的是男友式陪伴的钱，得到的却只是一个收费赶路人，换谁心里都不会舒服。

Image
但这件事也不能只怪陪爬者，很多消费者下单之前只看脸和身材，根本不问服务内容，也不看对方有没有户外经验。等真正上山以后，才发现自己购买的所谓“情绪价值”，根本没有统一标准。

双方从一开始就没有把话说清楚，消费者认为，几百元应该包括背包、搀扶、鼓励和照顾；陪爬者却可能认为，自己只负责陪着走完全程。

一个以为买的是贴身服务，一个以为卖的是同行时间，矛盾自然越来越多。

Image
2025年8月，两名女子带着一名5岁孩子，花费近3万元请来24名年轻男子陪爬泰山。陪爬者轮流抱孩子登山，还负责背物资、扇风、哄孩子。

相关视频传开后，迅速引发争议，有人认为，只要双方自愿，花自己的钱购买服务没有问题。

Image
可这件事真正值得警惕的，并不是有钱人会不会玩，而是它给行业做了一个错误示范：只要人数够多、场面够夸张、互动够亲密，一次普通陪爬就能变成热门视频。

后来者看到的，不再是如何锻炼体能、熟悉路线、掌握急救，而是怎样设计一个更容易走红的桥段。

Image
这就是陪爬行业现在最危险的地方，行业还没有形成明确标准，平台流量却抢先制定了一套标准：长得好看比熟悉路线重要，会拍公主抱比掌握急救重要，能制造暧昧感比能够处理突发情况更容易接单。

当流量开始奖励暧昧，专业自然就会被挤到角落里。

所谓“牵手加钱”“公主抱另算”，不一定是所有陪爬团队公开标出的收费项目，却反映出行业里一个越来越明显的问题：身体接触正在被当成一种可以交易的卖点。

Image
游客在陡坡上站不稳，陪爬者扶一把，这是安全帮助；游客体力透支，经过双方同意后背一段，也可以理解。

但如果把牵手、拥抱和公主抱提前拍成广告，故意利用亲密画面吸引顾客，那就已经偏离了陪爬的本质。

Image
此外，身体接触的边界，不能等到了山上再临时试探，更不能只靠一句“客人主动要求”，哪些情况可以搀扶，哪些动作必须提前征得同意，哪些服务根本不该提供，都应该在出发前说明白。

可现实中，大量陪爬交易仍通过社交平台私下完成，没有正式合同，没有统一价格，也没有明确的服务清单。有人交了定金，到了景区才发现对方失联。

Image
有人花了一对一的钱，见面后却被临时安排拼团；还有人宣传时承诺背包、拍照，真正上山后却全部变成额外收费。

这门生意表面看起来简单，背后却藏着不少风险，陪爬者带游客夜爬，遇到摔伤、中暑、低血糖怎么办？游客要求走野路，陪爬者要不要拒绝等等？

2026年3月，泰安市有关部门开展旅游行业专项整治，重点检查导游执业资质、服务规范和行程安排，并公开征集无证导游、虚假宣传、降低服务标准等问题线索。

Image
可陪爬行业的尴尬就在这里：它既不像传统导游那样有明确的资格要求，也不是朋友之间的免费同行。

有人长期接单、组建团队、收取定金、转介绍抽成，已经具备明显的经营属性，却依然披着“私人搭子”的外衣。

Image
出了问题，消费者找不到正式商家；需要监管时，从业者又可能表示，自己只是提供个人陪伴服务，所以，陪爬真正缺少的，不是一句空泛的“加强管理”，而是一张能够执行的服务清单。

一个行业想要长久，靠的必须是路线判断、体力管理、应急处理和服务信用，而不是把年轻人的脸、身材和肢体接触拿出来明码标价。

Image
泰山不缺流量，陪爬也不缺需求。现在最缺的，是有人把这门生意从滤镜里拽出来，重新放回规则中。

否则，当“会不会抱”比“能不能保障安全”更受关注时，陪爬爬得再高，也只是在往行业的下坡路上走。
