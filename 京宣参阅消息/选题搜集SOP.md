# 京宣参阅消息选题搜集SOP

## 一、适用范围

本SOP用于北京宣传部参阅消息的日常选题发现、核验、筛选和候选题报送。工作终点是形成可供编辑判断的候选题卡，不包括完整快报正文写作。

本SOP以同目录下的`guide.md`为唯一上位依据。执行时，三类材料必须分层使用：

1. `rule`是客户明示要求，属于硬约束，不能降格为一般经验，也不能自行删减。
2. `example`是客户点名认可或亲自修改后的正向样例，用于判断选题角度、材料组织和快报语感。
3. `result`是多家单位近期报送和采用记录，只能用于观察采用倾向。它不能替代客户规则，也不能据此断定某个选题未采的具体原因。

如本SOP与`guide.md`后续版本不一致，一律以最新`guide.md`为准。

## 二、选题工作的核心目标

参阅消息选题要同时解决四个问题：

1. 涉北京的热点、重点账号信息和突发舆情不漏报。
2. 全国重大政策、活动和重要行业变化中，与北京直接有关或值得北京关注的内容要及时发现。
3. 宣传思想和意识形态领域的文化文艺、网络舆论、网梗等苗头要能够识别。
4. 外地事件、涉外信息、文旅、民生、人工智能等议题不能泛泛搜集，必须有明确的报送价值。

其中，涉市信息是第一优先级，要求发现后快速核验、快速报送。非涉京选题不能为了报送而生硬拼接北京关系。它本身具有全国性、行业性或明显借鉴意义时，应直接说明其价值。

## 三、客户硬规则转化表

| 客户要求 | 执行动作 | 交付前检查 |
| --- | --- | --- |
| 重点关注微博 | 每轮巡检先看微博热搜、同城热点和重点账号，再补充其他平台 | 是否完成微博全量扫榜，而非只依赖关键词搜索 |
| 涉市热点不能漏报 | 建立涉京关键词、重点主体和重点场景清单；涉京线索先进入核验池，不因信息不完整直接略过 | 当轮热搜和重点账号中的涉京信息是否逐条处理 |
| 同时关注小红书、B站、知乎、抖音、快手、头条 | 按平台特点补充现场内容、用户体验、青年文化、行业讨论和下沉传播 | 候选题是否只来自单一平台；需要观察多平台反应的题目是否完成补充 |
| 全国重大政策、活动，尤其涉及北京 | 监测权威发布后的舆论反响、执行疑问和北京相关影响 | 是否只摘录政策内容，遗漏真实舆论反应 |
| 关注文化文艺和宣传思想领域 | 持续监测文艺作品、电影电视剧、文化场馆、演出、宣传物料、主流媒体和文化企业 | 是否发现作品争议、版权伦理、内容导向、市场变化和机构声誉问题 |
| 关注网络舆论场和网梗 | 观察热词、戏谑表达、二创、标签化叙事及其外溢 | 是否能说明网梗正在指向什么现实情绪或价值争议 |
| 近期重点关注涉汛、基层风险 | 汛期加强气象、应急、交通、景区、山区活动和基层处置相关监测 | 是否存在现场视频或求助信息尚未核验 |
| 关注外地重点新闻的北京借鉴意义 | 只选择风险场景、行业模式或治理问题与北京有明显对应关系的事件 | 与北京的关系是否需要绕多步才能成立；如是，则降级或删除 |
| 涉市信息重点快报 | 设立涉京快速通道，发现后立即核验，不等候常规批次 | 是否因追求材料完整而错过时效 |
| 不要格式化、公式化、八股化 | 候选题卡讲清具体事件、当下讨论和报送理由，不使用万能风险句 | 换一个事件后原文是否仍然成立；如成立，说明表达过于模板化 |
| 研判建议不要过细 | 选题阶段只提示应关注的舆论方向，不代替具体部门设计处置方案 | 是否出现对其他单位具体工作的指挥式表述 |

## 四、监测范围与平台分工

### 1. 微博主监测面

微博是第一发现平台，每轮必须完成三条路径：

1. 扫榜：完整查看热搜、文娱榜、要闻榜和同城相关内容，记录所有涉京项目。
2. 盯号：查看重点媒体、北京本地资讯账号、政务及公共机构、行业账号和有稳定爆料能力的大V。
3. 搜词：以地点、主体和场景词补足未上榜信息。

涉京关键词库至少分为以下几组，并根据采用结果持续更新：

- 地域词：北京、首都、进京、在京及各区名称。
- 机构词：在京高校、医院、文化场馆、景区、交通枢纽、公共服务机构。
- 企业词：在京互联网、人工智能、文化传媒、影视、文旅和重要消费企业。
- 场景词：暴雨、积水、山区、徒步、交通、演出、展览、招生、就业、投诉、侵权、辟谣、通报。
- 宣传思想词：电影、电视剧、短剧、话剧、出版、文艺评论、主流媒体、宣传物料、网梗、二创、价值观。

关键词库不是固定词表。新出现的机构、人物、事件标签和网络用语，应在复盘后补入。

### 2. 其他平台的补充作用

| 平台 | 主要观察内容 | 使用边界 |
| --- | --- | --- |
| 小红书 | 北京本地体验、文旅消费、公共服务、校园和职场感受 | 用户笔记先作线索，事实需另行核验 |
| B站 | 青年文化、影视文艺、二创、网梗和长视频评论 | 注意区分作品评价、玩梗和真实事件 |
| 知乎 | 政策解释、行业判断、高校及科技讨论 | 高赞回答不等于权威结论 |
| 抖音、快手 | 突发现场、基层风险、涉汛求助、下沉舆论 | 视频时间、地点和原始发布者必须核实 |
| 头条 | 地方新闻、行业账号、自媒体扩散和跨平台转载 | 防止把转载链条误当作多个独立信源 |

其他平台不是平均用力。微博发现涉京热点后，可到短视频平台核对现场传播，到小红书观察体验型反馈，到知乎和行业媒体补充争议背景。

## 五、每轮选题搜集流程

### 第一步：完成涉京防漏扫描

每轮先扫微博热榜和重点账号，逐条标记：

- 涉北京地点、机构、企业、人员或政策执行。
- 全国事件中出现明确的北京影响。
- 北京媒体、文化机构、高校、科技企业成为争议主体。
- 突发公共安全、涉汛、交通、景区、户外活动和基层处置信息。

直接涉京但事实尚不完整的线索，进入“紧急核验”，不能因暂时无法成稿而从候选池消失。

### 第二步：补充规定议题

完成涉京扫描后，再按客户关注范围补充：

1. 全国重大政策和活动的舆论反响。
2. 文化文艺阵地、作品、影视剧、演出、宣传物料和文化市场变化。
3. 网络舆论场、网梗、标签化叙事和青年文化。
4. 涉汛及基层治理风险。
5. 对北京有直接借鉴意义的外地重点事件。
6. 涉外、文旅、民生、人工智能及重大法规议题。

补充选题要看“新情况”而非大类是否齐全。某一类别当天没有达到报送标准的内容，可以空缺，不能为了凑类别降低门槛。

### 第三步：判断是否值得进入候选池

对每条线索依次回答：

1. 现在报是否有时间价值？
2. 事实是否发生了新变化，或舆论是否出现了新焦点？
3. 它是否直接涉京，或属于客户明确关注的领域？
4. 当前是否已经形成可观察的舆论反应？
5. 核心事实能否通过可靠信源确认？
6. 能否用一句具体的话说明“为什么此刻值得报”？

前五问中有明显短板的，转入观察池。一句话只能写成“引发关注”“值得重视”等空泛表述的，暂不报送。

### 第四步：完成事实核验

核验至少覆盖：

- 时间、地点、主体、事件进展和当前状态。
- 原帖、原视频或原始报道是否存在。
- 是否已有官方通报、当事方回应或权威媒体报道。
- 热传截图、录音和视频是否存在剪辑、错配、旧闻翻炒或张冠李戴。
- 同一内容是否只是多家账号转载同一来源。

涉及未经证实的死亡、违法、学术不端、企业经营、录音爆料等内容，不能把传言写成事实。若“谣言传播”本身具有报送价值，题卡应明确写成“某账号炒作”“网传信息引发讨论”，并把已核实事实与传言分开。

### 第五步：提炼真实舆论焦点

候选题不能只交代“发生了什么”，还要说明“大家在争什么”。优先提炼已经出现的观点，不预设未来因果。

可从以下角度整理：

- 不同群体关注点是否不同。
- 讨论是否由事件本身延伸到政策、公平、机构声誉、行业模式或价值观。
- 是否出现戏谑、标签化、地域化、民族化或意识形态联想。
- 是否有媒体、行业人士、消费者、游客、从业者等不同立场。

禁止用“如果后续出现A，就会导致B”的假设链条制造风险。客户需要的是已经出现或具有明确现实基础的讨论，不是远距离推演。

### 第六步：排序并决定处理方式

候选题分为四档：

| 档位 | 处理方式 | 典型情形 |
| --- | --- | --- |
| A档，即时报 | 完成最低限度核验后立即报送 | 涉京突发、公共安全、涉汛、重点机构声誉、重大政策涉京反响 |
| B档，优先报 | 补齐舆论和信源后尽快报送 | 全国硬新闻、文化宣传领域重要变化、科技经济重要议题 |
| C档，观察 | 等待官方回应、更多传播或新进展 | 事实不完整、热度刚起、舆论焦点尚不清楚 |
| D档，淘汰 | 记录原因，不进入本轮报送 | 旧闻翻炒、重复报送、低可信爆料、牵强涉京、二手争论 |

A档优先于背景材料和观点收集的完整度，但不能降低核心事实核验门槛。先把已经核实的关键事实、当前舆论焦点和链接报出，后续如有明显增量再续报。

## 六、筛选判断表

筛选不采用机械总分。以下六项按“高、中、低”判断，并记录短板：

| 维度 | 高 | 中 | 低 |
| --- | --- | --- | --- |
| 涉京性 | 事件发生在北京，主体为在京机构，或直接影响北京 | 全国事件对北京有明确影响，或外地事件与北京同类场景高度对应 | 需要牵强解释才能与北京关联 |
| 时效性 | 正在发生、刚刚回应或热度快速上升 | 事件较新，讨论仍在发展 | 旧闻翻炒，热度和事实均无新增 |
| 议题级别 | 重大政策、公共安全、重要经济科技、重点机构和广泛民生 | 行业变化或群体性讨论 | 普通个案、明星琐闻或局部口水战 |
| 领域契合 | 直接属于客户列明的重点方向 | 可从明确角度进入客户关注范围 | 只能依靠泛化风险表述进入 |
| 舆论增量 | 多类主体形成实质争议或讨论明显外溢 | 单平台热度较高，已有清晰观点 | 只有转发，无稳定讨论 |
| 事实可靠性 | 有原始信源、权威信息和相互印证 | 核心事实可确认，部分细节待核 | 主要依赖匿名爆料、录音截图或单一自媒体 |

处理原则：

- 涉京性高、时效性高的题目优先进入快速通道。
- 事实可靠性低的题目不得因热度高直接报送。
- 非涉京选题必须在议题级别、领域契合或借鉴价值上有一项明显突出。
- 采用记录只能作为同等条件下的排序参考，不能覆盖客户硬规则。

## 七、近期采用结果反映的选题信号

以下判断来自`guide.md`中的近期采用记录，属于工作推断，不是客户明示规则。

### 1. 采用较多的方向

- 北京本地突发和公共风险，如丰台出租房偷拍、通州车辆落水、北京徒步团被困。
- 在京重要机构和公共文化主体，如北大公众号、国家大剧院、正阳门、北京日报。
- 涉京政策和城市运行，如智能消费补贴、初高中贯通培养、进京旅客携带无人机规定。
- 国家级科技、经济硬新闻，如国产光刻机、长鑫存储、财政自给率、脑部基因编辑临床事件。
- 文化影视和行业模式，如暑期档电影市场、AI短剧上星、“只有河南”项目易主。
- 境外账号对涉京或全国敏感事件的炒作，但报送对象是“炒作行为及传播”，不是对传言本身背书。

### 2. 未采题目呈现的风险信号

- 主要依赖录音、传言或个人爆料，事实基础不足。
- 旧内容再次翻炒，缺少新的事实和舆论增量。
- 外地个案与北京关系弱，也没有形成全国性议题。
- 涉外议题距离北京和当前重点较远，报送理由泛化。
- 围绕既有报道展开的二手批评，事件级别和新增价值有限。
- 同一选题已在此前采用，再报时没有明显新进展。

未采可能还受报送时间、同题竞争、稿件质量和当日版面影响。复盘时只能记录相关性，不能把上述现象写成确定原因。

### 3. 对中科数科的调整方向

近期记录中，中科数科采用数量少于部分单位。仅凭结果表无法判断是报送数量、时点还是选题质量造成，因此不作单一归因。实际工作中先做以下调整：

1. 把微博涉京防漏和快速报送放在首位，减少只找“适合深度分析”题目的倾向。
2. 候选池不要长期只偏向单一类型。涉京快题之外，还要持续留意全国硬新闻、文化宣传和AI等客户点名方向。
3. 参考其他单位的成功方向建立监测词和主体清单，不照搬已经报过的具体题目。
4. 非涉京题目不强造北京关系。“只有河南”最终采用稿说明，行业模式、文化内容和消费者讨论本身成立时，可以直接从议题价值切入。
5. 对已报和已采用题目建立台账。没有事实、政策、回应或舆论结构的新变化，不重复报送。

## 八、优秀样例的选题方法

### 1. 奥森民族团结柱

该题的发现入口是微博北京本地大V，事件直接涉京，且涉及公共景观、城市记忆和民族议题。它的价值不只来自热度，还来自三类已经出现的讨论：政策联想和戏谑表达、设施维护解释、城市记忆和保留诉求。

可复制的方法是：本地重点账号发现线索，核实基本背景，整理不同群体观点，再判断讨论是否从具体处置延伸到敏感议题。

### 2. “只有河南”和建业电影小镇易主

该题不是北京本地突发，但属于文化文艺、文旅和行业模式议题。最终样例没有生硬强调北京资本或北京创作者，而是直接写交易、经营困境、消费者担忧和重资产文旅模式变化。

可复制的方法是：外地题目先判断其全国行业价值，再寻找媒体、消费者和业内人士的真实观点。题目本身成立时，不必牵强搭建北京关联。

### 3. 两篇样例的共同点

- 标题包含具体事件和主要舆论焦点。
- 开头快速交代最新事实，不长篇铺垫背景。
- 舆论观点有来源群体和真实差异，不是统一套用“一是、二是、三是”。
- 判断落在当前已经出现的风险、争议或行业问题上。
- 建议保持原则性和方向性，不替相关单位设计具体处置步骤。

## 九、候选题卡模板

每条候选题按以下格式记录：

```markdown
### 候选题名称

- 发现时间：
- 首发或原始信源：
- 当前传播平台：
- 题目类别：涉京／重大政策活动／文化文艺／网络舆论和网梗／涉汛基层风险／外地借鉴／涉外／文旅民生AI
- 处理档位：A档即时报／B档优先报／C档观察／D档淘汰
- 核心事实：只写已经核实的时间、主体、事件和最新进展。
- 舆论焦点：按实际讨论归并观点，通常为两至四类，并注明主要发声群体，不强行凑数。
- 报送理由：用一句话说明为什么此刻值得北京宣传部门关注。
- 北京关系：直接涉京／全国政策影响北京／外地同类场景借鉴／无直接关联但具全国或行业价值。
- 待核问题：
- 重复情况：此前是否报送、采用或出现同类题。
- 信源链接：
- 处理意见：
```

题卡中的“报送理由”是筛选关键。合格表述应指向具体对象和具体问题，如“在京重要文化机构使用AI物料引发版权争议”，不能只写“事件引发关注，存在舆情风险”。

## 十、涉京漏报检查清单

每轮报送前必须完成以下检查：

- 微博热搜、同城内容和重点账号是否全部扫过。
- 热榜中是否有北京地点、在京主体、进京政策或北京媒体参与。
- 北京高校、文化场馆、文旅项目、科技企业和公共机构是否出现新争议。
- 涉汛、交通、山区活动、景区和基层求助是否有新现场内容。
- 小红书和短视频平台是否出现尚未上微博热搜的北京本地集中投诉。
- 当前候选池是否遗漏客户明确列出的文化文艺、网络舆论、民生、AI等方向。
- 已淘汰的涉京线索是否写明原因，是否需要继续观察。
- 是否存在因材料尚不完整而被误删的涉京突发。

只要最后一项无法确认，就不能结束本轮扫描。

## 十一、复盘与清单更新

每次收到采用结果后，完成三项记录：

1. 标记本单位每条题目的发现时间、报送时间、采用结果及可能影响因素。
2. 记录其他单位采用题目的方向、首发平台、涉京程度和题目类型。
3. 更新重点账号、关键词、重复题台账和观察池。

复盘重点不是统计谁采用得多，而是回答：

- 哪类涉京信息发现得慢或没有发现？
- 哪些题目事实可靠，但报送角度没有抓住客户当前关注？
- 哪些题目因为重复、牵强关联或缺乏舆论增量浪费了时间？
- 其他单位采用题目的线索入口，能否转化为新的监测账号、关键词或场景？

连续积累采用记录后，再调整筛选优先级。单日结果不宜直接改写规则。

## 十二、最终出池标准

一条题目进入报送池前，应同时满足：

1. 属于涉京信息，或客户明确关注的议题范围。
2. 具有现实时间价值，不是无增量的旧闻。
3. 核心事实可以核验，传言与事实已经分开。
4. 已形成具体舆论焦点，不靠假设未来后果制造风险。
5. 报送理由具体，能说明北京宣传部门为什么需要现在看到。
6. 与近期已报、已采用题目相比有新的事实、角度或舆论变化。

涉京突发满足前五项后应快速报送。非涉京选题还要额外证明其全国性、行业性或北京借鉴价值。无法证明的，留在观察池，不为凑数报送。
