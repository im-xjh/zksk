# 通用检索规范

## 事实核验原则

第一，优先核验关键事实，而不是平均用力。最需要核验的是会影响整篇判断的事实，例如时间节点、官方名称、数字、伤亡、政策结论、涉外表述。

第二，事实核验要看最新口径。天气、职务、政策、赛事、市场数据等都会变化，不能凭印象写。

第三，引用外媒、台湾岛内媒体、境外社交平台时，要明确其属性和事实强度。可以写“部分外媒将其解读为……”，但不能直接把外媒解读当作事实。

第四，不要为了分析而跨事件硬串。两个事件可以在整体判断中形成背景关系，但单条案例分析要围绕本事件展开。若某一事件本身没有出现某个事实，就不要把另一个事件硬塞进来证明观点。

第五，要检查前后逻辑是否冲突。例如前文判断某方仍在持续操弄某叙事，后文就不宜写其“转向”另一叙事而未加限定。

## 媒体来源标注

如果引用了媒体来源，则标明：xxx媒体，几号发文，并且为了核查，在该句末尾用（）标注链接。除非是完成最终稿件前的修改，（）内容应该删除。

如果引用媒体来源，正文中应写清“某媒体某月某日发文/报道称”，并在该句末尾用括号标注链接，便于核查。

重要观点不能只写“有人说”，否则像AI补空位。能落到具体媒体、具体人物、具体日期，就更像真实报告。

不宜写：

“岛内在野阵营也借此质疑，过去民进党籍地方首长亦曾赴大陆行销农产品。”

宜写：

“国民党立委洪孟楷、国民党前发言人杨智伃等人质疑，过去陈菊、赖清德、潘孟安等民进党地方首长曾赴大陆交流、行销农产品或洽谈产业合作，如今国民党籍县市长以视频方式替台东农民推销农产品却被威胁查处，相关说法见Yahoo新闻6月17日报道和凤凰网转载海峡导报6月18日报道。”

## 检索输出格式

检索完成后，先将结果输出为 Markdown 格式的表格内容，再做观点归并和写作判断。不要只输出散点列表，也不要直接跳到正文。

常规检索材料表可使用以下格式：

| 序号 | 来源类型 | 来源/平台 | 时间 | 标题/对象 | 主要内容摘录 | 链接 | 采用方式 |
| ---- | -------- | --------- | ---- | --------- | ------------ | ---- | -------- |
| 1 | 媒体报道/官方通报/社媒帖文/评论 |  |  |  |  |  | 纳入事实/纳入舆论/背景参考/不纳入 |

境外社媒检索使用下文“境外社媒检索素材表”。

## 境外社媒检索输出规范

让AI检索X、Reddit、Facebook、Instagram、Threads、YouTube等境外社交平台时，必须先说明可见性边界。普通网页检索通常只能看到公开索引到的帖文、标题、摘要、视频简介、少量评论片段或无需登录即可访问的公开内容，不能等同于进入平台后台查看完整评论区。

输出时要把“可核验材料索引”和“舆论判断”分开。先列可回链核验的材料，再基于材料做观点归类。报告最终以判断为主，不追求学术统计意义上的样本严谨，但材料表阶段必须保留来源和链接，方便回看。

## 检索素材表格式

第一步先输出“境外社媒检索素材表”，字段建议如下：

| 序号 | 平台 | 事件/议题 | 账号/频道/社区 | 内容摘录 | 链接 | 可见性说明 |
| ---- | ---- | --------- | -------------- | -------- | ---- | ---------- |
| 1 |  |  |  |  |  |  |

各字段写法如下：

1. 平台：写X、Reddit、Facebook、Instagram、Threads、YouTube等。
2. 事件/议题：如果检索要求是多议题的，则需要这个字段，对应报告中的具体事件，不要写得过泛。
3. 账号/频道/社区：能公开看到就填写；看不到则写“公开索引未显示”。
4. 内容摘录：尽量摘录原帖标题、正文关键句或评论原文，仅做直接翻译成简体中文；不要在素材表中替它过度发挥。
5. 链接：必须保留可回链链接，方便复核。
6. 可见性说明：标注“可读全文”“仅见标题/摘要”“评论区不可完整查看”“动态加载，样本有限”等。

## 不同平台的颗粒度处理

Reddit：以一条讨论内容为单位。Reddit公开性相对较高，若帖子和评论可访问，应尽量按“帖子”或“单条评论”拆分。一个帖子下如果有多条有代表性的评论，可以分成多行，每行对应一条评论。若检索不到相关集中讨论，应明确写“未检索到与本事件直接相关的集中讨论帖”，不要用旧闻或无关帖凑数。

X：以单条公开帖文链接为单位。X的回复、转推和引用可见性不稳定，网页检索常只能看到帖文正文或搜索摘要。除非能打开并读取具体回复，否则不要写“X网友评论认为”。

Facebook：以公开帖文链接为单位。Facebook评论区受账号登录、发帖人设置和算法排序影响较大。输出时以公开帖文正文、媒体账号转发语、可见标题为主。若评论不可完整查看，应在可见性说明中写明“评论区不可完整查看”。

Instagram：以公开贴文/Reel链接为单位。Instagram常见情况是只能看到图片、短视频标题、说明文字、账号名或搜索摘要。除非评论区可读且样本明确，否则只作为“公开帖文素材”处理。

Threads：以单条帖文链接为单位。Threads适合记录意见账号、媒体账号、政治人物账号的原帖观点。若同一账号在同一帖中包含多个观点，可以在一行中概括；不要把同一帖拆成多条，除非有多条独立回复可读且有链接。

YouTube：以视频链接为单位。YouTube检索通常能看到视频标题、频道，评论区则受登录、排序、地区、频道设置影响。

## 平台样本平衡

检索时不要过分依赖Facebook。X、Reddit、YouTube、Threads、Instagram等平台都应尽量覆盖。若某个平台没有有效样本，应说明“未检索到直接相关讨论”或“公开索引结果多为无关内容”，不要用无关材料补数。

素材表可以按平台列，但进入报告正文时，不建议按平台分别写“Facebook认为、X认为、Reddit认为”。更适合按观点类型归并。检索输出阶段可以分平台；正式舆论观点部分应按观点集合和立场差异组织，而不是按平台堆材料。

## 写进报告时的表述口径

报告以判断为主，不以学术统计为目标。公开检索样本不完整时，正文可以根据已检索到的代表性材料作适当概括、放大和强调，但不能编造不存在的来源、数据和原话。

可以写：

- “公开社交平台上，相关讨论主要以媒体账号、意见账号和个人帖文形式扩散。”
- “从可公开检索到的帖文看，相关声音集中指向……”
- “相关讨论显示，该议题已被部分账号用于攻击大陆立场、放大‘中国威胁’叙事。”
- “尽管公开样本有限，但相关表述与既有反华叙事高度一致，值得警惕。”
- “部分岛内和境外账号借题发挥，将具体事件包装为政治议题。”

谨慎使用：

- “网友普遍认为……”
- “评论区一边倒……”
- “全平台热议……”

如果要使用类似判断，必须有多来源、多平台或高热度材料支撑。没有充足材料时，改写为“部分账号”“相关声音”“可见讨论中”“公开帖文中”。

## 检索指令模板

“请检索X、Reddit、Facebook、Instagram、Threads、YouTube等平台关于【事件】的公开讨论。先说明普通网页检索的可见性边界。检索结果先输出为Markdown表格，字段包括：平台、事件/议题、账号/频道/社区、内容摘录、链接、可见性说明。Reddit按一条帖子或一条可读评论为单位输出；其他平台按一条公开链接、帖文或视频为单位输出。输出素材表后，再按观点类型进行归并总结，不要在正式舆论观点部分按平台机械罗列。”

更严格的版本：

“凡是无法打开全文、无法确认时间、无法确认账号或与事件无直接关系的材料，单独列入‘不纳入样本’表，不得用于事实判断。”
