# 海淀周报

## 适用范围

用于海淀区意识形态周报及同类固定周报材料。用户明确说明是海淀周报时，按本 profile 执行。

## 工作流

`search → writing → convert`

默认跳过 brainstorm。除非用户明确要求讨论选题或改版方向，否则直接进入检索和写作。

## Search

按周报周期检索本地重点事件、网络讨论、教育、民生、事故、敏感节点和意识形态相关风险。材料需保留来源、日期、链接和可核验信息。

检索时优先确认：

1. 事件是否发生在本周或对下周仍有影响。
2. 是否涉及海淀本地、北京本地或与海淀相关主体。
3. 是否已有官方通报、媒体报道或平台公开信息。
4. 是否存在现实触发点，如开学、考试、天气、活动、施工、政策执行、节假日、重大会议等。
5. 是否可能在小红书、微博、抖音、公众号、社区论坛、家长群、高校社群等渠道扩散。

## Writing

按海淀周报固定结构输出 Markdown。重点写清事件事实、舆情焦点、风险触发点和下周关注事项。表达应服务工作判断，避免空泛口号。

写作时遵守通用写作规范：事实、舆论、研判分开；研判要回答风险来自哪里、什么条件会让它发酵、应该关注哪些平台、群体或部门。

每条材料至少说明：

1. 发生了什么。
2. 为什么值得关注。
3. 舆论可能围绕什么问题展开。
4. 下周或后续有什么触发点。
5. 建议关注哪些渠道、部门或处置环节。

## Convert

使用海淀周报专用转换器。Markdown 写作时提前遵守该转换器限制：仅支持 `#` 一级标题；图片必须独占一行；网络图片将被拒绝；文本若看起来像章节标题但未使用 `#` 可能报错。
