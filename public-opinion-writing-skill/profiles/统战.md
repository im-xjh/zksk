# 统战

## 适用范围

用于统战、涉台、涉两岸交流、岛内政治叙事、污名化统战、台湾联系窗口等相关稿件。用户明确说明是统战类稿件时，按本 profile 执行。

## 工作流

`search → writing → convert`

默认跳过 brainstorm。必要时只做“角度选择”，不做发散式选题扩展。

## Search

围绕事件事实、岛内媒体、政治人物表态、相关机构回应、境外社媒公开讨论进行检索。境外社媒材料先输出可核验素材表，再按观点归类。

检索时注意平衡平台，不要过分依赖Facebook。X、Reddit、YouTube、Threads、Instagram等平台都应尽量覆盖。若某个平台没有有效样本，应说明“未检索到直接相关讨论”或“公开索引结果多为无关内容”，不要用无关材料补数。

重要材料优先落到：

1. 具体媒体、日期、链接。
2. 具体政治人物、机构或账号。
3. 具体原话或可核验摘要。
4. 公开可见性边界。
5. 是否纳入正文判断。

## Writing

按事实、舆论、研判组织。舆论部分按观点类型归并，避免按平台罗列。涉台、涉外、涉统战表达需区分事实、对方叙事和我方研判。

正式舆论观点部分更适合按观点类型组织，例如：

1. 支持两岸交流、认为民进党泛化“统战”标签。
2. 质疑相关活动具有政治动员色彩。
3. 从民生、农产品、体育观看、文娱交流角度批评当局过度政治化。
4. 绿营意见账号将事件包装为“认知作战”“统战渗透”。
5. 中性或技术性讨论，如转播权、市场销售、活动审批程序等。

## 类型定性

写作时要先判断事件的主属性。主属性决定后文风险判断和处置建议：

- 伏羲祭典：主属性是文化和民俗，不宜主定性为宗教。
- 凤梨释迦：主属性是农产品销售和基层民生，不宜只写成参加海峡论坛。
- 世界杯转播：主属性是体育观看便利和版权付费问题，不宜只写成两岸口水战。
- 张凌赫：主属性是青年文娱交流，不宜只写成明星站台。

主属性一旦错，后面的分析就会偏。

## 建议写法

针对“污名化统战阻断两岸交流”这类稿件，建议应从事件本身生长出来：

1. 不只解释统战概念，而要揭示交流被阻断的具体代价。
2. 把“谁有权定义正常交流”作为舆论攻防点。
3. 降低基层交流对单一大型平台和高政治能见度场景的依赖。
4. 防止我方传播中过度使用刺激性、胜利式表达，被绿营反向截取为“统战证据”。
5. 保存岛内支持正常交流的温和原声，少依赖大陆媒体替台湾民众下判断。
6. 围绕“交流安全感”提供更细致的服务，不要只号召多交流。

建议要能对应前文事实。前文写农民，就要有农民销售、采购、渠道的建议；前文写青年文娱，就要有保护粉丝和艺人交流安全感的建议；前文写文化祭典，就要有低政治化、连续化、民俗化交流的建议。

## 禁止事项

- 不把不同事件硬串。
- 不把对方叙事写成事实。
- 不把媒体解读直接写成报告判断。
- 不按平台机械罗列舆论。
- 不把事实支撑不足的问题强行拔高。
- 不写成旁观式、理中客式材料；在事实基础上明确站稳中国官方立场。
