# 天津摘编

## 适用范围

用于天津摘编、境外敏感信息专报、入册材料压缩整理及同类摘编型稿件。用户明确说明是天津摘编或提供既有材料要求压缩入册时，按本 profile 执行。

## 工作流

`writing → convert`

默认跳过 brainstorm 和 search。用户提供的材料是主要依据。只有用户明确要求补充核验、查找出处或更新事实时才检索。

## Search

默认不检索。若必须检索，只核验会影响正文判断的关键事实、来源、日期、人物职务、机构名称、政策文件和链接。

不主动扩展材料，不把摘编任务变成新稿件写作任务。

## Writing

以摘编、压缩、规范化为主。保留核心事实、判断和必要出处，删去重复背景、弱相关展开、过度评论和无法支撑正文的材料。

写作时重点处理：

1. 保留材料原意，不拔高、不改写成立场更满的判断。
2. 压缩重复事实和背景。
3. 统一来源、日期、主体和表述口径。
4. 区分媒体报道称、外媒解读、社媒声音和报告判断。
5. 不主动加入未经用户提供或未经核验的新材料。

## Convert

按天津摘编对应模板或转换方式处理。若使用“境外敏感信息专报”转换器，应提前遵守限制：不支持图片、表格、三级及以上标题；正文通过模板填充 `{{TOC}}` 和 `{{BODY}}` 占位符。
