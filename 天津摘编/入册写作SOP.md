# 入册写作SOP

## 适用场景

本 SOP 用于将境外媒体报道、英文报道翻译稿或当日选题资料整理为可进入“境外敏感信息专报”的入册正文。

入册稿不是简单摘抄原文，也不是把原始翻译稿机械压缩，而是对材料进行选题、定角度、抽事实、重组逻辑、降敏表达和中文顺稿，形成适合内部专报使用的信息条目。

## 成稿目标

单条入册正文一般控制在约 900—1100 字符，接近 1000 字左右。成稿应做到：

- 标题稳妥，体现议题主线和涉华关联；
- 首段交代来源、时间、主体和核心事实；
- 正文有背景、有数据、有影响、有趋势或回应；
- 表述客观克制，不替外媒负面判断背书；
- 删除链接、网页残留和明显翻译腔；
- 全文不出现“指出”。

## 基本结构

推荐采用 4 个层次展开：

1. **来源与核心事实**：交代媒体、日期、报道对象和主要事件。
2. **背景与关键数据**：补充政策、市场、产业链、金额、比例、增长率、时间节点等信息。
3. **影响与风险**：说明该议题对中国企业、产业、政策环境、国际竞争或外部舆论的影响。
4. **回应与趋势**：补充相关机构、企业、专家或政府表态，或说明后续不确定性。

实际写作时可根据材料压缩为 3 段，也可扩展为 5—8 段，但每段都应服务于标题主线。

## 标题处理

### 标题不宜直接照搬原文

境外媒体标题通常更新闻化、冲突化或带疑问句。入册标题应改写为内部专报语体。

常用标题模式：

- `媒体名：主体 + 动作 + 影响/趋势`
- `外媒关注 + 议题 + 风险/变数`
- `美西方 + 政策/动作 + 对中国相关领域影响`
- `中国企业/产业 + 进展/压力/争议/不确定性`

### 标题要求

- 用陈述句，不用疑问句；
- 少用口语化、营销化和夸张表达；
- 对涉华负面指控不要直接放大，可转为“争议”“外方声称”“政策影响”等角度；
- 尽量体现涉华主体、核心事件和判断方向。

示例：

| 原始线索标题 | 入册标题处理 |
| --- | --- |
| 日本半导体设备对华销售减一成，中国国产化取得进展 | 日本半导体设备对华销售下滑 中国国产化加速 |
| 对中国汽车保持开放的德国电车补贴政策，会面临变数吗？ | 德国纯电补贴对华开放 政策未来存变数 |
| Anthropic指控阿里巴巴“非法”获取人工智能模型 | 应改为更稳妥的争议/回应/政策影响角度，避免直接放大“非法”指控 |

## 原始资料到入册的对照规律

2026-06-25 成品的入册条目主要来自三份原始资料，而不是 `20260625境外动态（中科数科）.txt` 这一份线索清单本身。对应关系如下：

| 入册成品条目 | 原始资料位置 | 加工特点 |
| --- | --- | --- |
| 日本半导体设备对华销售下滑 中国国产化加速 | `0625昨晚或早上资料.md`：日经中文网“日本半导体设备对华销售减一成，中国国产化取得进展” | 原文较长，入册保留销售额、国产化率、美国管制、企业表态等主干，删去过细企业背景，标题由口语化“一成”改为趋势判断“下滑/加速”。 |
| 德国纯电补贴对华开放 政策未来存变数 | `0625昨晚或早上资料.md`：FT中文网“对中国汽车保持开放的德国电车补贴政策，会面临变数吗？” | 原文疑问句改为陈述式标题；入册保留补贴金额、开放规则、中国车企销量和欧盟内部争议，形成“当前利好—未来不确定”的结构。 |
| 阿里起诉美国国防部 否认与中国军方关联 | `0625补充资料.md`：纽约时报“阿里巴巴起诉美国国防部，否认与中国军方有关联” | 选取比“Anthropic指控阿里巴巴非法获取模型”更稳妥的事件角度，以阿里诉讼和否认为主线，弱化外方攻击性指控。 |
| 字节跳动拟筹200亿海外贷款增加AI投资 | `0625补充资料.md`：彭博社“字节跳动寻求史上最大规模的全球贷款，金额达200亿美元” | 入册保留贷款规模、期限、AI资本支出、全球科技企业AI投入背景，形成企业融资服务AI布局的主线。 |
| 摩根士丹利大幅上调中国人形机器人出货预测 | `0625早十点补充选题.md`：CNBC“摩根士丹利将中国人形机器人出货量预测值翻了一番，原因是商业化进程加速” | 入册保留 5万台、20亿美元、2030年150亿美元等关键数据，同时补充政策支持、供应链和海外扩张。 |
| OpenAI与博通发布首款定制AI芯片 | `0625补充资料.md`：CNBC 和彭博社关于 OpenAI 与博通芯片的两篇报道 | 入册合并两家媒体信息，保留芯片用途、成本节约、部署时间、供应商组合等互补信息，形成一条完整技术产业动态。 |

由此可见，入册写作通常不是只取单份线索清单，而是从昨晚/早上资料、早十点补充选题、补充资料中选择最适合的完整报道，有时还会合并同一议题下多家媒体的互补信息。

## 原文使用原则

### 可以保留

- 时间、地点、人物、机构、企业名称；
- 金额、比例、市场份额、出货量、预测值等硬数据；
- 政策名称、监管措施、制裁或补贴规则；
- 企业、政府、研究机构的正式表态；
- 与涉华议题直接相关的背景和影响判断。

### 需要改写

- 直译腔明显的长句；
- 英文报道中的复杂从句、插入语和被动表达；
- 情绪化、攻击性或未经平衡的判断；
- 过长背景铺垫；
- 原文标题中的疑问句、比喻、口语化说法；
- 对中国主体的强定性指控。

### 应删除

- URL 和网页参数；
- 原始资料中的栏目标签；
- 重复背景；
- 与涉华主线关系弱的国外细节；
- 多个相似专家观点中的次要观点；
- 可能造成误读的绝对化判断。

## 润色幅度

入册稿允许较大幅度重组，但不能改变事实。

可进行的加工包括：

- 调整段落顺序，使其符合“来源—事实—背景—影响—趋势”的专报逻辑；
- 合并短句，减少翻译腔；
- 用中文机关文风重写原文长句；
- 删除边缘细节，突出涉华主线；
- 将外媒判断转化为“外媒称/报道关注/有分析认为”的转述口吻。

不可进行的加工包括：

- 编造材料中没有的数据；
- 把外媒观点写成我方结论；
- 删除必要来源限定；
- 为追求立场而扭曲原文事实。

## 敏感表达处理

入册稿应保持“转述境外舆论”的视角，不替外媒或外方机构背书。

### 禁用和慎用

- 禁用：`指出`
- 慎用：`指控`、`非法`、`威胁`、`窃取`、`间谍`、`打压`、`围堵`

### 推荐替换

| 原表达 | 建议替换 |
| --- | --- |
| 指出 | 称、表示、认为、提到、数据显示、报告显示 |
| 指控 | 指称、声称、称、外方称、美方称 |
| 非法 | 涉嫌、被指、所谓“非法”、相关争议 |
| 中国威胁 | 对华担忧、涉华风险叙事、外方疑虑 |
| 窃取、间谍 | 外方声称、所谓安全风险、相关指控 |
| 打压、围堵 | 限制、管制、审查、施压 |

涉及外方负面定性时，必须保留来源限定，例如：

- `美方声称……`
- `报道称……`
- `外媒渲染……`
- `相关报告称……`
- `该公司否认……`

## 英文、数字和标点规范

- 中文与英文缩写之间一般不额外加空格：`AI芯片`、`Claude人工智能模型`、`OpenAI和博通`。
- 数字与中文单位连写：`1000亿美元`、`5万台`、`30亿欧元`、`36.4%`。
- 日期用中文习惯：`6月25日`、`2025财年`、`今年1至5月`。
- 使用中文标点：中文逗号、句号、冒号、括号。
- 首次出现英文机构或产品名可保留英文，后文避免重复括注。

## 常用句式

- `6月×日，××报道称，……`
- `报道称，随着……，……`
- `数据显示，……`
- `受……影响，……`
- `在……背景下，……`
- `相关人士称，……`
- `报告预计，……`
- `该公司表示，……`
- `不过，……仍存在不确定性。`
- `这一趋势可能对……产生影响。`

## 操作流程

1. **选题**：从当日资料中选择涉华相关度高、风险或价值明显的报道。
2. **定角度**：明确主线是产业进展、外方限制、政策变数、企业应对、市场趋势还是舆论风险。
3. **改标题**：把新闻化标题改为稳妥、陈述式、专报化标题。
4. **抽事实**：提取核心事实、关键数据、政策背景、表态和影响判断。
5. **重组正文**：按“来源—事实—背景—影响—趋势”排序。
6. **降敏处理**：对负面指控和外媒立场加来源限定，避免直接背书。
7. **顺中文**：去除翻译腔，合并短句，压缩重复背景。
8. **格式复核**：删除链接，统一标点、英文、数字和单位。

## 交付前检查清单

- [ ] 单条约 900—1100 字符，信息量足够。
- [ ] 标题为稳妥陈述句，未照搬冲突化外媒标题。
- [ ] 首段交代媒体、日期和核心事实。
- [ ] 保留关键数据、主体、政策和影响。
- [ ] 删除 URL、网页残留和无关背景。
- [ ] 没有“指出”。
- [ ] 涉华负面判断均有来源限定。
- [ ] 没有把外媒观点写成我方判断。
- [ ] 英文、数字与中文之间没有多余空格。
- [ ] 标点、日期、单位格式统一。
