# 摘编报送工作流说明

## 一、工作目标

在“摘编”文件夹下，每天从收到的境内外媒体资料中筛选重要涉华信息，整理形成面向天津网信办、中央网信办、北京市网信办报送的简明稿件。

工作核心是：

1. 从原始资料中筛选最值得报送的10条左右信息；
2. 按固定类别归纳；
3. 保留每篇文章的标题、来源、链接和开头导语；
4. 形成一份可直接发送客户的简洁版报送内容；
5. 最终稿件一般保存为Word文档，也可先输出Markdown文本供校对。

## 二、输入材料

### 1. 原始资料文件

每日原始资料通常位于：

`摘编/`

命名形式一般为：

`MMDD昨晚或早上资料.md`

例如：

`摘编/0626昨晚或早上资料.md`

这类文件是当天收到的境内外媒体信息汇总，通常包含：

- 目录；
- 分类栏目；
- 每篇文章标题；
- 原文链接；
- 日期；
- 正文翻译或摘录内容。

### 2. 参考成稿文件

可参考此前已提交版本，例如：

`摘编/天津0625上午报送.md`

或最终提交的Word文档，例如：

`摘编/20260626上午境外动态（天津）.docx`

参考重点不是复杂格式，而是：

- 筛选标准；
- 分类方式；
- 每条信息保留哪些字段；
- 文字简洁程度；
- 面向客户的报送语气。

## 三、筛选原则

### 1. 总量要求

每期原则上筛选10条。

如原始资料不足或质量较低，可适当少于10条，但通常应尽量保持10条。

### 2. 重要性优先

优先选择以下类型：

- 涉及中美关系、对华科技限制、经贸摩擦、供应链重组的文章；
- 涉及中国科技、产业、AI、芯片、汽车、新能源等重点领域的文章；
- 涉及中国经济、金融、人民币国际化、房地产、消费、出口等重要议题的文章；
- 涉及美西方内部对对华政策进行反思、批评或调整的文章；
- 涉及台湾、签证、留学、APEC、外交争议等敏感或政策相关内容的文章；
- 有较强决策参考价值、舆论观察价值或趋势判断价值的文章。

### 3. 媒体选择原则

尽量选择相对主流、信息价值较高的境外媒体，例如：

- 路透社
- 彭博社
- 金融时报 / FT中文网
- 南华早报
- 日经亚洲 / 日经中文网
- BBC
- 福布斯
- Foreign Policy
- 亚洲新闻台
- 观察家报
- 法广网等

尽量避免或慎用以下来源：

- 大纪元；
- 自由亚洲电台；
- 自由时报；
- 明显敌对、反华色彩浓厚或议题煽动性过强的媒体；
- 内容明显低质、缺乏事实支撑、标题党严重的文章。

但如果当天涉及重大敏感事件，且其他来源没有覆盖，可根据需要酌情保留，并放入“对华攻击”类别。

### 4. 避免低相关信息

以下内容一般不优先选入：

- 与中国关系不大的国际自然灾害、天气、事故；
- 纯商业资讯但涉华价值不高的文章；
- 重复度较高、角度相似的信息；
- 只涉及一般社会新闻、地方琐事、非重点舆情的信息；
- 来源明显不适合向客户报送的内容。

例如，`0626昨晚或早上资料.md` 中“欧洲热浪持续肆虐”与涉华报送关系较弱，一般不纳入天津报送稿。

## 四、分类规则

最终稿件分为三类：

1. 对华攻击
2. 客观理性声音
3. 美西方内部批评反思文章

### 1. 对华攻击

放入明显从负面角度评价中国、质疑中国政策、渲染中国风险、指责中国制度或对华采取限制措施的文章。

常见内容包括：

- 指责中国经济存在风险；
- 渲染中国科技、产业发展泡沫；
- 批评中国金融政策、去美元化、产业政策；
- 美国或西方限制中国学生、科研人员、企业；
- 对中国外交、制度、治理的负面叙事；
- 对涉华敏感事件的负面报道。

示例：

- 彭博社：现在对中国经济松口气还为时过早
- Foreign Policy：中国的去美元化运动遭遇瓶颈
- 法广网：美拟限缩国际学生签证停留期限 最长仅4年 中国留学生恐受冲击

### 2. 客观理性声音

放入相对客观、中性，或从产业、技术、市场角度描述中国发展的文章。

这类文章不一定完全正面，但重点是事实性、分析性较强，没有明显攻击性。

常见内容包括：

- 中国企业技术进展；
- 中国企业出海；
- 中国芯片、汽车、AI、制造业发展；
- 外企为中国市场调整策略；
- 外媒承认中国市场重要性或产业竞争力；
- 对中国优势与挑战进行平衡分析。

示例：

- 日经亚洲：高通公司将根据美国出口限制规定，设计一款专为中国市场设计的数据中心芯片
- FT中文网：大变局下的“新中式”出海
- 日经中文网：不止EV，中国发动机也在猛追日本

### 3. 美西方内部批评反思文章

放入重点批评、反思或揭示美西方自身问题、误判、政策代价、竞争短板的文章。

这类文章的核心不是直接写中国好，而是指出：

- 西方对中国存在误解；
- 美国或西方封锁政策可能失败或反噬；
- 美国保护主义、签证限制、出口管制等带来自身损失；
- 西方企业、政府、社会需要重新理解中国；
- 中国竞争力迫使西方反思自身产业和政策。

示例：

- BBC：中国芯片出口额暴增110%，是否意味西方“封锁失败”？
- 观察家报：达沃斯夏季论坛揭示了西方对中国的盲点
- 亚洲新闻台：重塑美中人工智能竞赛格局的，不是技术，而是人才
- 福布斯：艾睿铂称，中国在全球汽车产业中占据主导地位

## 五、数量分配

总数一般为10条，三个类别尽量均衡。

推荐分配方式：

- 对华攻击：3条
- 客观理性声音：3条
- 美西方内部批评反思文章：4条

即“3/3/4”。

如果当天材料结构特殊，也可以调整为：

- 4/3/3
- 3/4/3
- 2/4/4

但应避免某一类过少，例如只有1条“美西方内部批评反思文章”就不够均衡。

## 六、每条信息保留内容

每篇只保留最基本内容，不需要复杂加工。

每条包含：

1. 序号；
2. 媒体名称；
3. 原标题；
4. 原文链接；
5. 开头导语。

### 1. 标题格式

格式为：

`序号. 媒体：标题`

例如：

`1. 路透社：中国大力发展“未来产业”引发风险投资热潮，泡沫担忧加剧`

### 2. 链接

标题下方单独放原文链接。

例如：

`https://www.reuters.com/world/asia-pacific/chinas-future-industries-push-triggers-flood-venture-capital-bubble-concerns-2026-06-24/`

### 3. 导语

链接下方放文章开头导语。

要求：

- 不需要自己重新概括；
- 直接复制原始资料中正文开头第一段；
- 如第一段过短，可复制前两段，但通常一段即可；
- 不要改写成评论性文字；
- 不要自行添加判断；
- 保持原文已有表述。

例如：

`SpaceX历史性地上市仅两天后，一家中国航天初创公司便举行了首轮融资的投资者路演，并宣称其使命是帮助中国在太空竞赛中赶上美国。`

## 七、格式要求

用户当前要求是最基础文字格式即可。

### 1. Markdown初稿格式

可先输出Markdown，格式如下：

```markdown
天津0626上午报送：

【对华攻击】

1. 路透社：中国大力发展“未来产业”引发风险投资热潮，泡沫担忧加剧

https://...

导语文字。

2. ...

【客观理性声音】

4. ...

【美西方内部批评反思文章】

7. ...
```

### 2. 不需要的格式

当前不需要：

- 加粗；
- 表格；
- 复杂标题样式；
- 摘要再加工；
- 日期字段；
- 正文长段落；
- 目录；
- 图片；
- 编者按；
- 来源说明；
- 额外分析。

### 3. 序号

序号应从1连续排到10，不按类别重新从1开始。

例如：

- 对华攻击：1、2、3
- 客观理性声音：4、5、6
- 美西方内部批评反思文章：7、8、9、10

## 八、命名规则

### 1. 原始资料命名

原始资料通常命名为：

`MMDD昨晚或早上资料.md`

例如：

`0626昨晚或早上资料.md`

### 2. Markdown初稿命名

如需要保存Markdown初稿，可命名为：

`天津MMDD上午报送.md`

例如：

`天津0626上午报送.md`

### 3. 最终Word文档命名

提交给天津的最终Word文档建议命名为：

`YYYYMMDD上午境外动态（天津）.docx`

例如：

`20260626上午境外动态（天津）.docx`

其中：

- `YYYYMMDD` 为报送日期；
- `上午境外动态` 为固定说明；
- `（天津）` 表示报送对象；
- 扩展名为 `.docx`。

如为下午或其他批次，可相应改为：

`YYYYMMDD下午境外动态（天津）.docx`

## 九、从原始资料到成稿的操作步骤

### 第一步：读取原始资料

打开当天文件，例如：

`摘编/0626昨晚或早上资料.md`

先看目录，了解当天文章总量、来源和主题。

### 第二步：初筛明显不适合内容

剔除：

- 大纪元等敌对媒体，除非确有必要；
- 与中国无关或关联弱的国际新闻；
- 地方性、琐碎性、低价值内容；
- 重复主题中价值较低的一篇；
- 过于敏感且来源不适合客户报送的文章。

### 第三步：选出候选文章

优先挑选10—12条候选文章，再压缩到10条。

挑选时兼顾：

- 重要性；
- 来源可靠性；
- 主题覆盖面；
- 三类数量均衡；
- 是否适合报送给天津网信办。

### 第四步：分类

将10条分别放入三类。

建议优先保证：

- 对华攻击类有代表性；
- 客观理性类体现中国产业、科技、经济进展；
- 美西方内部批评反思类数量不少于3条，最好4条。

### 第五步：复制导语

对每条文章，从原始资料正文开头复制第一段作为导语。

注意：

- 不要自己总结；
- 不要加入“报道称”“文章认为”等改写；
- 如果原文第一段就是一句话，也可直接使用；
- 如果第一段缺乏完整信息，可顺延复制第二段。

### 第六步：整理为Markdown初稿

形成结构清晰的文本稿：

- 标题；
- 三个类别；
- 连续编号；
- 每条标题、链接、导语。

### 第七步：检查

检查以下内容：

- 是否正好10条；
- 三类是否基本均衡；
- 是否误选大纪元、自由亚洲、自由时报等不优先来源；
- 是否有与中国无关的文章；
- 序号是否连续；
- 链接是否完整；
- 导语是否来自原文开头；
- 是否有多余加粗、转义符、乱码；
- 日期和文件名是否对应。

### 第八步：生成最终Word文档

如需要正式提交，将Markdown内容整理为Word文档。

最终文件命名为：

`YYYYMMDD上午境外动态（天津）.docx`

例如：

`20260626上午境外动态（天津）.docx`

5. FT中文网：大变局下的“新中式”出海  
6. 日经中文网：不止EV，中国发动机也在猛追日本  

### 美西方内部批评反思文章

7. 福布斯：艾睿铂称，中国在全球汽车产业中占据主导地位

## 十一、注意事项

1. “美西方内部批评反思文章”不能太少，最好保持3—4条。
2. “客观理性声音”不等于全部正面，只要相对事实性、产业性、分析性强即可。
3. “对华攻击”也不必全选极端反华媒体，主流媒体中负面涉华分析更适合报送。
4. 尽量不用大纪元、自由亚洲、自由时报等来源，除非没有替代材料且议题重要。
5. 导语只复制，不重写。
6. 不需要复杂格式，客户需要的是快速浏览和信息判断。
7. 文件名要体现日期、上午/下午、境外动态、天津。
8. 最终稿件应保持简洁、干净、可直接复制发送。

## 十二、补充规则：中科数科 / 中央网信办版本

除天津上午报送外，有时还需要根据同一批“昨晚或早上资料”和“早十点补充选题”，整理面向中科数科或中央网信办的版本。此类版本可参考：

- `20260625境外动态（中科数科）.txt`
- `20260626境外动态（中央网信办）.md`

### 1. 数量要求

中科数科或中央网信办版本一般要求共20条，数量需严格控制，不多不少。

### 2. 分类要求

仍按三类整理：

1. 对华攻击点
2. 客观理性声音
3. 美西方内部批评反思文章

但三个类别不必像天津10条版本那样严格均衡。原因是当天材料中“美西方内部批评反思文章”可能相对较少，或某一类材料质量更高，可根据材料结构灵活分配。

如同一选题也出现在天津版本中，应尽量保持分类一致。例如：

- “中国大力发展‘未来产业’引发风险投资热潮，泡沫担忧加剧”归入“对华攻击”；
- “高通公司将根据美国出口限制规定，设计一款专为中国市场设计的数据中心芯片”归入“客观理性声音”；
- “艾睿铂称，中国在全球汽车产业中占据主导地位”“中国芯片出口额暴增110%，是否意味西方‘封锁失败’？”“达沃斯夏季论坛揭示了西方对中国的盲点”“重塑美中人工智能竞赛格局的，不是技术，而是人才”归入“美西方内部批评反思文章”。

### 3. 写作格式

中科数科 / 中央网信办版本与天津版本格式不同，通常采用：

`标题。日期，媒体来源报道，导语。`

下一行放链接。

例如：

```markdown
**1.中国大力发展“未来产业”引发风险投资热潮，泡沫担忧加剧。**6月25日，路透社报道，SpaceX历史性地上市仅两天后，一家中国航天初创公司便举行了首轮融资的投资者路演，并宣称其使命是帮助中国在太空竞赛中赶上美国。
https://...
```

如用户要求保存为Markdown：

- 不需要段首缩进；
- 序号及标题需要加粗；
- 标题后接日期、媒体来源、导语；
- 链接单独一行；
- 类别标题不一定加粗，按用户当次要求执行。

### 4. 导语处理

导语仍以原始资料开头为准，不自行评论，不扩写。

可根据篇幅选择开头一句或一小段，避免过长；如第一句已能说明主题，可只摘录一句。

### 5. 表述检查

整理完成后，应检查：

- 是否正好20条；
- 是否删除了用户明确不要的选题；
- 是否加入了用户明确要求补充的选题；
- 中文标点是否统一；
- 表述是否自然、干净；
- 尽量避免使用“指出”一词，可改用“报道”“表示”“称”“认为”等，但不要改变原意；
- 重复选题的分类是否与天津版本保持一致。

### 6. 文件命名

可按报送对象命名，例如：

- `YYYYMMDD境外动态（中科数科）.txt`
- `YYYYMMDD境外动态（中央网信办）.md`

## 十三、WPS密码提醒

只有发送给天津的最终稿件需要加上WPS密码，其他报送对象版本不用加密码。
