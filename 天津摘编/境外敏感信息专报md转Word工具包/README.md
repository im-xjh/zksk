# 境外敏感信息专报 Markdown 转 Word 工具包

本工具用于把“境外敏感信息专报”Markdown 草稿转换为带固定封面、目录和正文样式的 Word 文档。

## 日常使用

### 双击使用

双击 `一键转Word.cmd`，在弹出的窗口中选择 Markdown 文件，工具会在同目录生成同名 `.docx`。

### 拖拽使用

把 `.md` 文件拖到 `一键转Word.cmd` 上，也会自动转换。

### 命令行使用

```bash
python convert.py INPUT.md [-o OUTPUT.docx] [--force] [--no-open] [--toc-pages manual|blank|estimate]
```

常用参数：

- `-o, --output`：指定输出 Word 路径。
- `--force`：不询问，直接覆盖已有文件。
- `--no-open`：生成后不自动打开 Word。
- `--toc-pages manual|blank|estimate`：覆盖 Markdown 中的目录页码模式。
- `--template TEMPLATE.docx`：指定其他模板。

## Markdown 格式

文件必须保存为 UTF-8 或 UTF-8 with BOM。

推荐格式：

```markdown
---
title: 境外敏感信息专报
issue: 第93期
issue_date: 2026年6月26日
toc_pages: manual
---

## 1｜日经中文网｜2026年6月24日｜日本半导体设备对华销售下滑 中国国产化加速｜1

正文第一段……

正文第二段……

## 2｜FT中文网｜2026年6月24日｜德国纯电补贴对华开放 政策未来存变数｜4

正文第一段……
```

每条信息使用一个二级标题 `##`，标题字段用全角竖线 `｜` 分隔：

1. 序号
2. 媒体名
3. 日期
4. 中文标题
5. 目录页码（`manual` 模式必填）

正文段落用空行分隔。

## 目录页码模式

本工具第一版不依赖 Word 自动目录。原因是 `python-docx` 无法准确计算 Word/WPS 的最终分页，参考文档中的目录字段也不适合稳定自动更新。

支持三种模式：

- `manual`：生产推荐。每条 `##` 标题末尾手动填写目录页码；缺页码会报错。
- `blank`：目录页码写为“待核”，适合初稿。
- `estimate`：按文本长度粗略估算页码，仅供草稿使用；生成后必须人工核对。

**最终报送前务必打开 Word/WPS 核对目录页码。**

## 模板说明

默认模板：

```text
templates/境外敏感信息专报模板.docx
```

模板内必须保留以下占位符，且每个占位符必须独占一段：

- `{{TOC}}`：目录条目插入位置。
- `{{BODY}}`：正文插入位置。

不要在 Word 中拆分、删除或改写这些占位符。若占位符缺失，转换会失败。

## 固定排版

正文默认使用：

- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 行距：固定 28 磅
- 正文首行缩进：约 2 字符
- 页码：正文节页脚居中，从 1 开始

封面和目录版式主要由模板保留。

## 当前限制

第一版暂不支持：

- 图片
- 表格
- `###` 及更深层级标题
- 自动精确计算目录页码
- 摘编模式

如需图片、表格或摘编 Word，可后续单独扩展。

## 常见错误

### 缺少字体

如果提示缺少 `仿宋_GB2312` 或 `黑体`，请先在 Windows 中安装相应字体，否则 Word 可能替换字体并导致分页变化。

### manual 模式缺少页码

`toc_pages: manual` 时，每条标题必须包含第 5 项页码：

```markdown
## 1｜媒体｜日期｜标题｜1
```

### 输出文件已打开

如果目标 `.docx` 正在 Word/WPS 中打开，可能无法覆盖。请关闭后重试，或换一个输出文件名。

### 模板占位符缺失

请检查模板中是否仍有独占一段的 `{{TOC}}` 和 `{{BODY}}`。
