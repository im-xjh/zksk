# 摘编写作SOP

## 适用场景

本 SOP 用于将已经入册或拟入册的专报信息压缩为 300 字以内的摘编条目。摘编用于快速报送和浏览，强调短、准、密，不追求完整论证。

摘编通常不是从原始英文资料重新写起，而是在入册正文基础上二次提炼：保留主干，删除背景，压缩句式，留下最重要的事实、数据和影响判断。

## 成稿目标

每条摘编应做到：

- 300 字以内；
- 一条一段，不拆分多段；
- 开头为序号和标题；
- 正文包含来源、核心事实、关键数据和涉华影响；
- 不新增入册稿或原始资料之外的判断；
- 不因压缩而删除必要来源限定；
- 全文不出现“指出”。

## 基本结构

推荐结构：

```text
序号.标题。媒体报道，核心事实。关键数据。涉华影响或回应。趋势/变数。
```

示例结构：

```text
1.日本半导体设备对华销售下滑，中国国产化加速。日经中文网报道，中国半导体制造设备国产化取得进展。……
```

## 标题处理

摘编标题一般沿用入册标题核心，但更短、更直接。

规则：

- 标题控制在 20—35 字左右；
- 入册标题中用于分隔的空格，可在摘编中改为中文逗号；
- 标题后加句号，再接正文；
- 不使用疑问句、感叹句、营销化标题；
- 对涉华负面指控不直接放大。

示例：

| 入册标题 | 摘编标题 |
| --- | --- |
| 日本半导体设备对华销售下滑 中国国产化加速 | 日本半导体设备对华销售下滑，中国国产化加速。 |
| 德国纯电补贴对华开放 政策未来存变数 | 德国纯电补贴对华开放，政策未来存变数。 |
| 字节跳动拟筹200亿海外贷款增加AI投资 | 字节跳动拟筹200亿海外贷款增加AI投资。 |

## 从入册到摘编的样本规律

2026-06-25 摘编基本对应入册中的 6 个条目，压缩时不是重新回到原始报道改写，而是从入册稿中抽取“标题主线 + 来源 + 核心事实 + 关键数据 + 影响判断”。

| 摘编条目 | 对应原始资料 | 压缩重点 |
| --- | --- | --- |
| 日本半导体设备对华销售下滑，中国国产化加速 | `0625昨晚或早上资料.md` 日经中文网报道 | 保留销售额下滑、国产化进展、美国管制和企业判断，删除多数企业铺垫。 |
| 德国纯电补贴对华开放，政策未来存变数 | `0625昨晚或早上资料.md` FT中文网报道 | 保留补贴政策、对中国品牌开放、欧盟/德国争议和未来变数，删除长政策背景。 |
| 阿里起诉美国国防部，否认与中国军方关联 | `0625补充资料.md` 纽约时报报道 | 保留“起诉—否认—名单影响”主线，避免放大其他更攻击性的阿里相关选题。 |
| 字节跳动拟筹200亿海外贷款增加AI投资 | `0625补充资料.md` 彭博社报道 | 保留 200亿美元贷款、三至五年期限、AI资本支出、数据中心投入。 |
| 摩根士丹利大幅上调中国人形机器人出货预测 | `0625早十点补充选题.md` CNBC报道 | 保留 5万台、20亿美元、2030年150亿美元、商业化加速。 |
| OpenAI与博通发布首款定制AI芯片 | `0625补充资料.md` CNBC/彭博社报道 | 保留首款定制芯片、推理用途、约50%成本节约、2026年底部署和供应商多元化。 |

压缩时应优先保留最能支撑标题判断的数据；若原始资料有多篇同题报道，摘编只保留互补信息中最关键的 2—4 点，不展开媒体差异。

## 必须保留的信息

每条摘编优先保留 5 类信息：

1. **来源**：媒体、机构或“据知情人士透露”等。
2. **核心事实**：谁做了什么，与中国有什么关系。
3. **关键数据**：金额、比例、出货量、市场份额、时间节点等，一般保留 2—4 组。
4. **涉华影响**：对中国企业、产业链、政策环境、国际竞争或舆论的影响。
5. **回应或趋势**：中方/企业回应、政策变数、后续不确定性。

## 可以删除的信息

从入册压缩为摘编时，通常删除：

- 长背景和历史铺垫；
- 多个专家观点中的次要观点；
- 技术原理细节；
- 过细公司介绍；
- 多层时间线；
- 与中国关系较弱的国外市场细节；
- 重复数据；
- 链接、脚注和网页残留；
- “值得注意的是”“与此同时”等可有可无的过渡语。

## 压缩方法

### 1. 先确定一句话主线

用一句话回答：

```text
某媒体报道，某主体因某背景采取某动作，并对中国企业/产业/市场产生某影响。
```

### 2. 只选三类材料

每条摘编通常只保留：

```text
核心事实 + 关键数据 + 涉华影响
```

必要时增加：

```text
外方态度/中方回应 + 趋势变数
```

### 3. 多段合一段

入册中的多段正文要压成一个自然段。可用逗号、分号和短句连接，但不要写成过长、难读的复杂句。

### 4. 控制数据数量

数据是摘编的信息密度来源，但不宜堆砌。一般保留 2—4 组最能支撑标题判断的数据。

### 5. 超字数时优先删

如超过 300 字，按以下顺序删减：

1. 次要背景；
2. 第二、第三个专家观点；
3. 远期规划；
4. 非核心企业名单；
5. 修饰语和过渡语；
6. 低价值数据。

## 敏感表达处理

摘编更短，语境更少，因此更不能省略来源限定。

### 必须保留来源限定的情况

- 外方对中国企业的负面指称；
- “非法”“安全风险”“军方关联”等敏感说法；
- 外媒对中国市场、产业或政策的判断；
- 美西方政府、议员、智库的涉华表述。

### 推荐写法

| 风险写法 | 摘编建议 |
| --- | --- |
| 美国指控阿里…… | 美国将阿里列入相关名单，阿里提起诉讼并否认关联 |
| 中国威胁欧洲市场 | 欧盟部分人士对中国品牌增长表示警惕 |
| 非法获取 | 被指、相关争议、外方声称 |
| 中国冲击 | 所谓“中国冲击”叙事、外界对中国品牌增长的担忧 |

## 禁用与格式规则

- 禁用“指出”，改用“称、表示、认为、提到、数据显示、报告显示”。
- 中文与英文缩写之间不额外加空格：`AI芯片`、`OpenAI和博通`。
- 数字与单位连写：`200亿美元`、`30亿欧元`、`5万台`。
- 删除链接。
- 删除 Markdown 标记。
- 不使用复杂脚注或括注。
- 不新增材料外判断。

## 常用句式

- `××报道，……`
- `据知情人士透露，……`
- `数据显示，……`
- `受……影响，……`
- `该公司表示，……`
- `相关机构预计，……`
- `这可能推动……`
- `不过，……仍存变数。`

## 操作流程

1. **沿用或微调标题**：保留入册标题核心，改为摘编式短标题。
2. **保留来源**：首句写明媒体或消息来源。
3. **提取主干**：只保留主体、动作、结果、涉华关联。
4. **筛选数据**：选择 2—4 组关键数据。
5. **压缩背景**：背景最多保留一句，且必须服务标题。
6. **保留影响**：结尾落在产业影响、政策变数、企业回应或趋势判断。
7. **降敏复核**：确认没有把外媒观点写成确定事实。
8. **字数复核**：控制在 300 字以内。

## 交付前检查清单

- [ ] 每条 300 字以内。
- [ ] 每条为一个自然段。
- [ ] 有序号和短标题。
- [ ] 首句或前半部分交代来源。
- [ ] 保留核心事实和涉华关联。
- [ ] 保留 2—4 组关键数据或关键判断。
- [ ] 删除链接、Markdown 标记和无关背景。
- [ ] 没有“指出”。
- [ ] 涉华负面表述保留来源限定。
- [ ] 没有新增材料外判断。
- [ ] 英文、数字与中文之间没有多余空格。
