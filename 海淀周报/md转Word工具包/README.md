# 海淀周报 Markdown 转 Word 工具包

## 日常使用

1. 双击 `一键转Word.cmd`，选择需要转换的 `.md` 文件；或者把 `.md` 文件直接拖到 `一键转Word.cmd` 上。
2. 工具会在 Markdown 所在目录生成同名 `.docx`，并自动使用 Word 或 WPS 打开。
3. 如果同名 Word 已存在，工具会先询问是否覆盖。

首次运行会自动检查 `python-docx` 和 `Pillow`，缺少时自动安装。

## Markdown 格式要求

主标题必须是文档首个非空行，并以一个 `#` 开头：

```markdown
# 意识形态周报
```

所有一级标题同样必须添加一个 `#`：

```markdown
# 一、本周重点及敏感事件
# 二、本周涉意识形态典型案例分析
```

工具不会把纯文本标题或未加 `#` 的“一、……”自动识别为标题；发现疑似漏写时会停止转换并提示行号。`##` 及更深层级也不支持。

行首重点内容可使用 Markdown 加粗：

```markdown
**一是重点事项。**后面继续书写正文。
```

图片必须单独占一行，支持相对路径、绝对路径和 `file:///` 路径。宽幅图会适配正文宽度，竖版书封按约 5.5 cm 宽排版：

```markdown
![传播趋势图](assets/传播趋势图.png)
```

建议把图片保存在周报目录下的 `assets` 文件夹中，避免长期引用系统临时目录。图片不存在或引用网络图片时，转换会停止，不会生成漏图的 Word。

支持标准 Markdown 管道表格。表格列数必须保持一致。

## 命令行

```powershell
python convert.py INPUT [-o OUTPUT] [--force] [--no-open]
```

- `-o/--output`：指定 Word 输出路径。
- `--force`：直接覆盖已有 Word。
- `--no-open`：转换成功后不自动打开 Word。

## 固定排版

- A4；上下边距 2.54 cm，左右边距 3.18 cm。
- 主标题：方正大标宋简体、二号、居中，标题后空一行。
- 一级标题：黑体、三号、缩进两字符。
- 正文：仿宋_GB2312、三号、两端对齐、首行缩进两字符、固定 28 磅行距。
- 中文标点采用“压缩标点符号”；全文关闭孤行控制。
- 页脚：Calibri、小五号、居中自动页码。
- 表格：总宽 15.82 cm，整体居中并使用“文字环绕：环绕”；五列固定宽度依次为 1.40、2.81、8.00、2.10、1.52 cm。采用参考稿相同的约 17.2 磅垂直偏移并禁止与上下方文字重叠。正文微软雅黑 10 磅、左对齐；表头微软雅黑 11 磅、加粗、居中。
