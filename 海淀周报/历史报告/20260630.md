# 意识形态周报



# 一、本周重点及敏感事件

**一是海淀商业航天全链升级，太空算力新赛道加速成型。**6月29日，2026全球数字经济大会·太空算力论坛在海淀中关村展示中心举行，北京太空算力创新中心正式揭牌，太空操作系统开源标准体系发布，“天算星座”北京、合肥两座全新地面站投入运行。创新中心落地海淀北京卫星小镇，定位为国内首个以拉通产业链、协同上下游为核心使命的太空算力创新中心。此前不久，海淀企业国电高科获得全国首张卫星物联网商用试验许可。从“连得上”到“算得动”，海淀商业航天产业路径更加清晰，卫星正从被送上天的硬件，转变为可运营、可调度、可应用的数字基础设施。目前海淀集聚商业航天企业200余家，占北京市60%；全国60%以上的卫星高端人才扎根海淀。舆论关注点集中在产业升级信号与区域经济带动效应上，认为海淀正依托卫星小镇和人工智能产业基础抢占太空算力新赛道。

**二是2026高考放榜，海淀头部名校高分段优势引发教育舆情热议**。2026北京高考分数公布，680分清北线以上高分段考生中，海淀“六小强”中学占据绝对主导优势，区域顶尖教育资源实力再度凸显。其中人大附中以85名高分考生位居全市榜首，清华附中47人、十一学校29人紧随其后，其余多所区内重点中学均有亮眼表现，整体高分规模远超其他城区。该事件引发全网广泛讨论，舆情聚焦三大方向：一是热议海淀优质师资、学区配套与产业人才集聚形成的教育优势壁垒；二是聚焦教育资源区域分化、学区房溢价、升学内卷等问题，引发教育公平相关探讨；三是头部名校高分成绩进一步拉升清北录取预期，带动校外培优、升学规划需求升温。当前舆情以数据讨论为主，伴随家长群体教育焦虑情绪，易联动学区政策、义务教育均衡发展等话题持续发酵。

**三是谢娜北京演唱会在海淀华熙LIVE场馆被取消，引发对流量跨界巡演监管与市场底线的讨论。**6月28日大麦公告取消《快乐万岁·我们的青春》北京站，7800张票原1分钟售罄，主办方承诺票款7个工作日原路全额退还，连观众机票、酒店退改手续费也一并承担。导火索是《乘风2026》淘汰直播中谢娜当众掏手卡宣发商演，被指把公共舞台当宣传位，叠加“成都圆梦专场到35天火速全国巡演”的反差，超12万条投诉涌入监管平台。讨论围绕三点：一是“流量祛魅”信号，主持主业、无代表作的明星开巡演被视作割韭菜，官媒介入后市场快速回调；二是维权意识抬头，观众打12345投诉+主办方全损赔付，被舆论解读为“普通人守住市场底线”；三是海淀文娱消费场景监管敏感度，华熙LIVE作为五棵松商圈核心场馆，承接此类跨界演出未来审批、口碑门槛可能抬高。

**四是清华旧科普视频陷物化女性争议，高校内容价值观与审核引质疑。**6月27日起，抖音、小红书、微博陆续有网民发帖，指清华大学2017年发布的一则电气安全科普视频中，将“地线保护”拟人化为穿紧身兔女郎服饰、姿态讨好的女性形象，配词“请个地线保护当私人保姆”，画面后期还让人物“长尾巴”，被指物化女性、以性别凝视博眼球。原帖目前已不可见，#清华大学辱女# 话题在微博发酵，校方已删视频但未正式回应，网民质疑压热度、删评。讨论分三层：**一是**物化女性质疑，顶尖学府把安全装置与媚态女性捆绑，与科普正向价值观不符，性别议题基本盘情绪较强；**二是**审核机制缺失，视频2017年发、能过层层审核却未被纠偏，暴露高校新媒体、二级院系内容把关松散；**三是**意识形态延伸，有网民揪出画面中疑似日本国旗元素及日系仪器品牌，叠加“侵华大学”等极端表述，把性别议题往民族叙事扯。



# 二、本周涉意识形态典型案例分析

**一是轻型航空器碰撞高层建筑事故引发低空安全治理与信息环境双重反思。**6月26日，一架轻型运动航空器在朝阳区飞行中碰撞高层建筑，驾驶员死亡、13人受伤，主管部门正进一步调查。因事发首都核心区，事故迅速引发境内外高度关注，一是在官方调查结论公布前的信息真空期，部分境外媒体引用未经证实信息，报道偏离事实基础；二是“飞行员报复社会”“故意偏离航线”等猜测在境外社交平台扩散，容易把尚未定性的安全事故转化为对社会心态的负面标签。从治理层面看，在无人机管控趋严的背景下，有人驾驶轻型航空器如何进入敏感城市空间，可能成为舆论持续关注的问题。后续处置需避免让技术性事故调查被情绪化猜测带偏，及时围绕事故原因、责任划分和低空飞行管理规则作出权威说明。

**二是央视曝光高考志愿填报AI套壳乱象，“技术平权”被异化为“信息差收割”引发AI治理讨论。**6月25日，央视调查揭露高考志愿填报行业灰色产业链：所谓“十年名师”“资深规划师”实为入职两个月的新人，收费数千至数万元后打开免费AI工具照本宣科，机构负责人直言“没有初心没有道德”；部分机构将自考本科包装为“全日制本科”引流，每人收费两万元。教育部随后发布预警，四大AI厂商同步上线免费志愿工具。该事件触及三个层面的价值观与治理问题。其一，技术本应打破信息壁垒，却被重新包装为高价“专家服务”收割焦虑家庭，信息差从天然的“不知”变成了人为制造的“误知”，这是技术普惠落地过程中的深层风险。其二，机构利用家长“花钱买心安”心理精准收割，受害最深的是县域和农村家庭，部分家庭既难以承担高价咨询费，也缺乏辨别AI真伪的信息素养，信息洼地效应在AI时代出现了新维度。其三，AI工具在教育场景中缺乏足够的监管，大厂免费工具虽已上线但缺乏准确性、公平性和隐私保护方面的统一规范，行业秩序建设滞后于技术扩散速度。

# 三、下周风险研判

**就业领域：暑期实习入职与“AI提效”叙事叠加，青年就业情绪可能被放大。**7月起，互联网企业暑期实习生陆续入职，海淀辖区平台企业、研发中心和高校毕业生群体高度集中，岗位变化容易与毕业季就业焦虑同频传播。当前“AI提效”“业务收缩”“低转正率”等讨论已在职场社群持续出现，若出现实习岗位临时取消、入职后工作内容明显缩水、转正名额收紧或补贴住宿承诺落空等情况，相关帖文可能在脉脉、小红书、高校论坛和毕业生微信群集中扩散。建议提前关注各高校就业指导中心与企业HR的沟通动态，留意脉脉、小红书等平台的实习生社群情绪走向。

**气象领域：雷阵雨与闷热天气交替，暴雨后城市运行保障进入检验期。**本周海淀刚经历暴雨五次预警，下周风险重点应放在短时降雨、强对流和闷热天气交替对城市运行的影响上。老旧小区、低洼路段、地下空间和浅山区域仍需关注排水、倒灌、树木倒伏和地质灾害隐患；同时，雨后闷热可能带来蚊虫滋生、垃圾清运和社区环境投诉。建议提前关注易积水点位，强化降雨前后信息发布和现场处置反馈。

**平台经济领域：外卖平台“破卷向善”共识进入落地期，规则调整的预期落差需提前关注。**6月29日，美团、淘宝闪购、京东外卖围绕餐饮外卖商家降本增利达成五项共识，其中明确提出不开展“分钟级竞速”。下周若平台陆续细化执行方案，骑手、消费者和商家三方可能对政策落地执行产生预期落差。海淀高校、互联网企业和商圈集中，外卖订单密度高，需关注外卖消费群体对配送费变化、时效调整的敏感反馈在社群和社交平台上的扩散。

# 五、每周荐书

**1.《下一个五年：中国的战略选择与行动方案》**，由郑永年主编，浙江人民出版社于2026年3月出版。本书立足“十五五”开局阶段我国发展环境的新变化，围绕科技自立自强、现代化产业体系、全国统一大市场、高水平对外开放和全民共享机制等关键议题，系统研判未来五年中国式现代化建设的战略重点与行动路径。书中汇集多位专家学者的政策分析与实践思考，既关注国际格局调整和大国竞争带来的外部压力，也回应国内经济转型、产业升级和民生改善等现实命题。

**2.《坚持统筹发展和安全》**，由董振华、范晶著，经济科学出版社于2026年3月出版。本书紧扣“十五五”时期发展原则，系统阐释统筹发展和安全这一重大治国方略的理论内涵与实践要求。全书以总体国家安全观为指导，从筑牢发展安全根基、健全国家安全体系、提升风险防范能力、坚持党的全面领导等方面展开论述，强调高质量发展是安全的根基，高水平安全是发展的保障。该书对理解发展与安全的辩证关系、提升风险预判和治理能力具有现实参考意义，也有助于在网信、产业、社会治理等领域增强底线思维和系统思维。
