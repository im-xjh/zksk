# 意识形态周报

2026年7月22日至7月29日，涉“海淀”信息量[待补]条。本周区域舆情呈现“基础科研突破提振信心、前沿产业成果集中释放、科技企业形象争议伴生”的态势。王虹、邓煜获菲尔兹奖引发振奋的同时，两人长期海外求学任教经历也带动人才培养、科研环境和成果归属争议；海淀商业航天和脑机接口领域取得新进展；与此同时，月之暗面酒吧庆功画面及现场文案引发对科技企业文化和创新价值取向的讨论。下周需重点关注八一建军节特殊时间节点、科技类校外培训与暑期托管、高招录取及录取通知书诈骗等风险。

# 一、本周重点及敏感事件

**一是中国籍数学家王虹、邓煜首获菲尔兹奖，人才培养与科研环境话题成为舆论焦点。**7月23日，北京大学2007级本科校友王虹、邓煜双双获得菲尔兹奖，实现中国籍数学家在该奖项上的首次突破。消息发布后迅速登上微博、知乎等平台热榜。舆论除肯定两人长期钻研、挑战重大难题的科研精神外，争议主要集中在三方面：一是部分网民抓住两人海外求学任教经历，认为重大成果主要在国外取得，质疑国内人才培养和科研环境；二是对比法国总统马克龙致电祝贺王虹与新华社首发快讯最初未列获奖者姓名，猜测主流媒体在报道口径上存在顾虑；三是围绕人才“归属”、国际流动和国内基础研究评价机制展开讨论。两人均从北大求学起步，相关争议与海淀顶尖人才培养和科研创新形象紧密关联，部分负面言论易由个人经历延伸为对国内教育科研体制的质疑。

**二是月之暗面Kimi K3发布后酒吧庆功画面引争议，企业文化和科技创新价值取向受到审视。**7月16日，海淀企业月之暗面发布参数规模达2.8万亿的Kimi K3。7月26日前后，多名网友发布疑似该团队在北京酒吧庆功的照片，现场屏幕出现含粗俗英文用语的口号，企业联合创始人、总裁张予彤疑似到场。舆论主要聚焦三方面：一是肯定Kimi K3在模型规模、多模态能力和开源生态方面取得的新进展；二是质疑团队选择酒吧庆功并公开使用粗俗文案，与科技企业应有的专业形象不符；三是借相关画面质疑公司存在商业浮躁和网红化营销的问题。月之暗面作为海淀头部人工智能企业，相关画面和文案容易引发对属地科技企业公司风气、创新价值取向和产业浮躁的连带质疑，非技术争议也可能削弱Kimi K3创新成果的正面传播效果。

**三是海淀商业航天企业参与多星发射，空间碎片监测与太空算力进展受关注。**7月24日，力箭一号遥十五将5颗卫星送入预定轨道，其中包括海淀企业遨天科技研制的甘德一号01星、星火传明研发的西光贰号03星；搭载太空数据中心关键技术成果的“辰光一号”技术试验卫星也于同日进入预定轨道。甘德一号01星将用于商业空间碎片监测，“辰光一号”则承担太空数据中心相关技术的在轨验证。舆论认为多颗商业卫星成功入轨，展现了海淀科创企业在空间碎片监测、空天信息和太空算力等前沿领域的技术实力。海淀依托北京卫星小镇、科研院所和商业航天企业，正在加快形成卫星研制、技术验证和场景应用相衔接的商业航天产业链条。

**四是第四届中国脑机接口大赛在海淀启幕，区域全链条产业布局集中亮相。**7月24日，第四届中国脑机接口大赛在中关村国际技术交易中心开幕，吸引150余所高校、科研机构和科创企业、320余支队伍参赛，设置脑机编解码算法、轻量化采集设备、临床适配等15个细分赛道。海淀区同期发布脑机接口产业发展规划，三大产业公共服务平台落地，中关村（海淀）脑机接口产业集聚区已有20余个项目入驻，30余家属地企业集中展示创新成果。舆论肯定海淀在高校科研、医疗资源、创新企业和成果转化方面的集聚优势，认为赛事打通了实验室成果与临床、民用场景的转化通道，有助于加快技术验证、项目孵化和产业协同，进一步完善海淀脑机接口产业生态布局。

# 二、本周涉意识形态典型案例分析

**一是李权哲高铁占座及多轮回应失当，将一般出行纠纷放大为“明星特权”与规则公平争议。**7月24日，有网友称其同行乘客购买的高铁一等座被艺人李权哲占据。活动主办方起初将问题归因于第三方订票及“后续座位调整”，但国铁北京局石家庄客运段调查称，涉事车票出票后全程座位无变更。7月27日，李权哲道歉并承认本人及团队未仔细核实座位信息。事件因现场沟通失当、团队回应推诿而持续升级，舆论聚焦公众人物是否尊重普通乘客、经纪团队是否以组织安排替个人责任开脱。该事件说明，公众对身份特权和规则差别高度敏感，模糊事实、转移责任往往比最初过失更易消耗信任。平台既要保障当事人依法表达，也需防止“开盒”、侮辱攻击和无关人员牵连，引导讨论回到事实、规则和责任边界。

**二是反虐猫志愿者遭“开盒”、造谣和威胁，网络暴力由观点冲突升级为现实伤害。**据南方都市报等媒体报道，上海反虐猫志愿者“芝麻”（化名）举报群内虐猫视频后，其本人及家人的身份、住址、联系方式等被曝光，并遭造谣和威胁；家属称，其7月17日因不堪压力轻生，送医后脱离生命危险。上海警方已就邱某某涉嫌侵犯公民个人信息案刑事立案。舆论讨论主要聚焦三方面：一是“开盒”已由曝光举报者本人扩展至其家人，个人信息被用于现实威胁；二是造黄谣、污名化标签和跨平台搬运相互叠加，显著放大网暴伤害；三是相关群体以报复举报者为目的形成围攻，使普通人参与公共监督面临较高安全成本。该事件反映出“开盒”正在成为网络对立中的攻击工具，网络暴力也由情绪宣泄升级为有组织、跨平台并向现实生活延伸的持续性伤害。

# 三、下周风险研判

**特殊时间节点：八一建军节临近，涉军历史、英雄烈士和国防话题舆情敏感度上升。**2026年8月1日是中国人民解放军建军99周年，各类纪念活动内容将集中发布。相关节点政治性强、关注度高，需警惕个别账号通过戏谑军史、恶搞军人形象、歪曲英雄烈士事迹等方式博取流量。建议重点关注微博、短视频、军事论坛和高校社群中的涉军谣言、错误史观及侮辱英烈内容，及时做好线索核查和平台处置。

**教育领域：科技类校外培训与托管需求集中，收费、安全和虚假营销风险易引发家长投诉。**暑期“AI课”“机器人课”“编程营”等科技类校外培训进入集中开展阶段。北京市教委已提示科技类培训机构须具备相应资质，并对资金存管、实训设备和消防用电安全提出要求。海淀家长对科技教育需求较强，无证办学、夸大师资和升学效果、向个人账户收取大额预付款、退费困难等是主要投诉点，需关注培训机构网络营销、家长投诉聚合及冒充机构客服实施“退费”诈骗等线索。

**招生录取领域：高招专科录取和征集志愿进入收尾阶段，录取通知书诈骗风险上升。**专科普通批录取时间为7月30日至8月1日，高校录取通知书也将陆续寄送。考生和家长等待录取结果期间情绪较为敏感，不法账号可能假冒高校、招办或“内部人士”，通过仿冒网站、陌生链接套取身份证号、准考证号和银行卡信息。海淀考生规模大、高校密集，需关注网络中可能存在的招生诈骗信息，引导考生以考试院和高校官方渠道为准。

# 五、每周荐书

**1.《破壁：中国科技造浪者的前沿突围》，**由董倩著，文津出版社于2026年出版。本书以深度访谈和科技产业纪实的方式，聚焦自主芯片、人工智能、高端游戏、万物互联、无人机、脑机接口、超材料、鸿蒙生态、6G通信等前沿领域，呈现中国科技工作者和创新企业在关键核心技术攻关、产业壁垒突破及外部压力应对中的实践探索。全书不止介绍技术成果，也关注科研组织、产业协同、企业战略和人才成长等决定创新能否落地的深层因素，有助于理解新质生产力形成背后的长期积累、产业韧性与创新主体担当，为观察海淀科技创新生态和前沿产业发展提供参考。（https://www.cbbr.com.cn/contents/500/108454.html）

**2.《中国企业社会价值探索与实践》，**由国务院国资委研究中心、企业社会价值实验室编著，中国经济出版社于2026年出版。本书围绕企业如何在创造经济价值的同时更好服务国家战略、社会发展和人民需要展开，系统梳理企业社会价值的理论框架、评价方法与实践路径，并通过案例呈现企业在科技创新、绿色发展、乡村振兴、民生保障、员工成长和公益责任等方面的探索。该书将企业社会责任由单一公益投入拓展为与战略决策、经营管理和绩效评价相衔接的价值创造机制，有助于理解国有企业、平台企业和科技企业如何统筹发展质量与社会效益，也为推动属地互联网企业履行平台责任、优化社会价值导向提供参考。（https://wap.sasac.gov.cn/n2588020/n2877938/n2879671/n2879673/c33117177/content.html）
