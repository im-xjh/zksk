# 意识形态周报

2026年7月29日至8月5日，涉“海淀”信息量条。本周区域舆情呈现“高校学术争议集中发酵、涉企谣言与消费维权交织”的态势。其中，中国人民大学教授阎连科旧作与获奖感言被翻炒；“莫言家世考证”国家社科项目因研究方法、经费效益遭自媒体质疑；两名短视频用户用AI生成车祸视频抹黑小米汽车；美团闪购售假酒获“退一赔十”，线上买酒鉴定难引发平台责任讨论。下周需重点关注汛期旧图炒作和虚构灾情传播、8·15节点下抗战历史话题与高校争议交叉发酵、高校教育科研体制质疑等风险。

# 一、本周重点及敏感事件

**一是人大教授阎连科旧作与获奖感言被翻炒，相关讨论向历史叙事和高校责任延伸。**7月中旬，围绕中国人民大学教授、作家阎连科2005年小说《为人民服务》和其2021年纽曼华语文学奖获奖感言的帖文集中出现。部分网民认为，感言中“一颗糖”的故事淡化了日本侵华历史，并将其与获奖资格联系起来；评论区出现“收回荣誉”“别让他跑了”等情绪化表述。此事又发生在7月13日人大通报撤销其指导的硕士生蒋方舟学位、暂停其招生资格之后，阎连科对两项争议均未回应，讨论随之叠加。该事件叠加抗战历史记忆、高校学术治理等议题，牵扯海淀高校声誉，需留意情绪化言论的扩散走向。

**二是人大“莫言家世考证”国家社科项目受自媒体质疑，科研经费与结项评价成为讨论焦点。**7月29日，一篇自媒体文章质疑中国人民大学2016年立项的国家社会科学基金重点项目“莫言家世考证”。文章称，该项目立项经费35万元，2022年以“优秀”等级结项；其对项目论文的研究方法提出批评，认为相关论述较多依据莫言及其亲友的著述、访谈，对不同文本中的矛盾细节缺少充分辨析，也缺乏实地调查。由此质疑项目成果质量和经费使用效益，容易引出对国家社科基金评审和高校学术评价的讨论。该事件涉及海淀高校的科研资金使用和学术公信力，可能影响高校和评审机构形象。

**三是AI生成虚假车祸视频抹黑小米汽车，二次传播和旧争议嫁接问题需关注。**8月3日晚，海淀企业小米集团通报，两名短视频平台用户使用AI生成虚假车祸视频，抹黑小米汽车产品及公司高管。经警方查证，一人被行政拘留7日，另一人被行政罚款，相关侵权链接已删除。通报发布后，舆论普遍支持依法惩处，部分网民觉得罚轻了、震慑不够；也有人反映此前一直把相关视频当真，担心帖子删了动图还在传，造谣影响难以彻底消除。少量评论把虚假视频与小米汽车既有事故、车企旧争议混为一谈，说明澄清信息尚未完全覆盖已有认知。小米是海淀头部科技企业，类似谣言对属地AI企业和网络生态形象有连带冲击。对这类涉企AI造谣，重点不只在原视频下架，更在于跟踪动图、剪辑片段和“事故合集”等二次内容的传播链路。

**四是美团闪购店铺售假酒获“退一赔十”，线上买酒举证门槛与平台把关责任引发讨论。**6月初，消费者在北京旅游时通过美团闪购“美团名酒行”购买一瓶53度“青花20”汾酒，收货后发现外包装异常。其向购买地石景山和汾酒产地市场监管部门反映后，汾阳市市场监管局7月16日书面答复称，经汾酒厂鉴定，送检产品的外观特征、防伪标识和生产信息均与正品不符。经市场监管部门介入，美团作出“退一赔十”处理，涉事店铺已关停。舆论聚焦在线上买酒鉴定难：品牌方通常只认市场监管部门委托的鉴定，个人送检无门，消费者举证难、周期长，平台对第三方商家的入驻把关也连带被审视。此事反映出本地生活与电商平台消费领域存在高值商品售假鉴定难的问题，值得留意类似消费维权线索。

# 二、本周涉意识形态典型案例分析

**一是《奥德赛》北京首映礼主持人“半蹲递麦”引发争议，涉外场合文化自信与礼仪分寸受审视。**7月30日，导演诺兰携《奥德赛》主创在北京出席首映礼，双语主持人采访坐席上的外籍主创时屈膝、弓背递送话筒，与嘉宾形成明显高低差，相关画面经短视频传播登上多平台热搜。舆论质疑该动作超出配合机位和收音的必要范围，视觉上呈现“仰视”感；部分网民翻出其此前采访国内嘉宾时站姿挺直的画面对比，认为其对中外受访对象“选择性弯腰”，指责其“卑躬屈膝”“崇洋媚外”；更有网民将现场截图与1945年中国战区受降仪式照片拼接传播，借历史记忆强化情绪表达。分析认为，该争议已超出对主持人个人职业表现的评判，折射出公众对涉外场合文化自信与平等交流的敏感期待，任何看似细微的“过度谦卑”肢体语言，经短视频截取和情绪化传播，都可能被放大为自我矮化，使文化交流细节上升为价值观议题。

**二是6岁女童接受脑部基因编辑试验后死亡，前沿科研安全底线与伦理监管受审视。**2025年3月，上海交通大学医学院附属新华医院为一名患罕见神经发育疾病的6岁女童实施全球首例脑部碱基编辑治疗，7天后女童因严重免疫反应死亡，医院伦理委员会认定其死亡与治疗相关。舆论聚焦三层：一是临床前安全性评估是否充分，有专家指出高剂量病毒载体可诱发严重免疫反应，灵长类毒理数据早于伦理审查出现却未获充分重视；二是患儿家庭与科研团队信息不对称，家属在疾病压力下自费支持研究，其“自主选择”是否建立在充分知情基础上；三是科研诚信与监管是否到位，担忧个别团队为追求“全球首例”和论文产出而弱化伦理规范。分析认为，“技术跑在监管前面”的叙事会削弱公众对前沿科技的整体信任。类似事件提示，高校和科研机构需强化前沿科研的伦理审查、受试者权益保护和风险信息披露，科研评价亦应避免过度追求“首例”而忽视安全底线。

# 三、下周风险研判

**一是气象领域：主汛期强降雨叠加暑期出行，涉汛谣言易集中出现。**当前北京仍处主汛期。下周如出现短时强降雨、雷暴大风并叠加早晚高峰或暑期景区客流，道路积水、停电、树木倒伏和浅山区域险情等现场画面容易在短视频平台传播，并引出对预警、疏导和处置效率的质疑。同时，降雨期易出现旧图嫁接、虚构停运、夸大灾情等涉汛谣言，需同步做好权威信息发布和辟谣响应。

**二是教育领域：高校学术争议与人才培养讨论叠加，教育科研体制的舆论风险仍存。**本周蒋方舟学位撤销、阎连科导师责任与获奖争议、人大“莫言家世考证”项目经费质疑等讨论仍在持续，与菲尔兹奖得主王虹海外求学任教经历引发的培养体制讨论余温叠加，高校教育成为近期舆论敏感点。后续若出现新的学术不端或培养争议，相关讨论易由个案转向对教育科研体制的整体质疑，需关注微博、知乎、教育论坛等平台相关言论，引导高校及时回应、说明情况。

**三是历史叙事领域：8·15日本投降纪念日临近，抗战历史叙事敏感度上升。**8月15日是日本宣布无条件投降纪念日，抗战历史叙事与中日关系话题进入高敏感时段。本周围绕阎连科获奖感言中“一颗糖”故事的讨论，已出现质疑其淡化日本侵华历史的声音，相关讨论仍在发酵，若在纪念节点前后被重新关联，或与日本右翼言行、涉日影视作品讨论叠加，可能由个案争议扩展为历史观争论。需防范借历史话题拼接旧闻、渲染对立，引导相关讨论尊重历史、回归理性。

# 五、每周荐书

**1.《中国范式：中国式现代化自主知识体系的探索与构建》，**由张冠梓、冯希莹等著，中国社会科学出版社于2026年出版。本书立足中国式现代化的历史脉络和当代实践，按照历史溯源、范式确立、概念提炼、案例呈现、比较对话、未来前瞻的思路，系统总结中国式现代化在历史成就、实践路径、制度优势和文明特质等方面的经验，探索具有主体性、原创性和世界意义的中国式现代化知识范式，并提出推进“中国式现代化学”学科建设的构想。该书兼具政治话语、实践话语和学理话语，有助于理解和把握中国自主知识体系建设、国际话语权塑造与中国叙事能力建设，为开展意识形态工作和网上理论传播提供理论参照。

**2.《大国算力：重塑未来的中国力量》，**由孟祥飞主编，天津科技翻译出版有限公司于2026年出版。本书从国家能力和新型基础设施角度，系统梳理算力发展的技术逻辑与战略意义，阐释基础算力、智能算力和高性能算力的发展格局，分析“东数西算”、国产芯片、绿色算力、算力主权以及政务、医疗、制造等领域的应用实践，并讨论全球算力竞争背景下我国算力体系的发展短板与提升路径。算力是人工智能产业发展、数据安全和科技自立自强的重要支撑，该书有助于理解AI产业链背后的基础设施逻辑和核心技术安全议题，为观察海淀人工智能产业生态和数字化治理提供参考。
