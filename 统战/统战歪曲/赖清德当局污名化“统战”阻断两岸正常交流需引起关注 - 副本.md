# 赖清德当局污名化"统战"阻断两岸正常交流需引起关注

近期，赖清德当局围绕第十八届海峡论坛及相关两岸交流议题，连续把农产品推销、文化祭典、体育观赛、文娱互动等普通民间交往纳入所谓"统战"叙事。其值得关注之处在于，岛内当局将"统战"标签的使用范围明显扩大，已从政党和社团交流延伸到基层民生、传统文化、公共体育和青年娱乐生活等方方面面。赖当局未必能完全杜绝所有两岸交流，但正在通过行政审查、舆论羞辱等方式制造寒蝉效应，迫使岛内民众、地方政府、民间团体和艺人对大陆交流自我审查。对统战工作而言，这类变化需要高度警惕，赖当局真正要削弱的，正是两岸民众在日常往来中形成的亲近感、信任感和共同生活经验。

# 一、基本情况及事件争议

最先引发舆论集中发酵的是台东县长饶庆铃视频推销凤梨释迦被查事件。6月13日，第十八届海峡论坛在厦门举行，新华社报道称，论坛吸引超过6000名台湾各界人士报名参加，其中包括不少"首来族"和台湾青年。饶庆铃因陆委会禁止中央及地方公职人员参加海峡论坛，改以预录视频方式为台东凤梨释迦等农产品推介。岛内陆委会随后称其涉嫌违反《两岸人民关系条例》第33条之一，将请主管机关了解查处，并要求调查参与签约的相关农业团体。此事之所以迅速引发岛内争议，关键在于它触及农民生计。对台东地方而言，凤梨释迦外销大陆长期关系果农收入，饶庆铃回应称，自己是为农民找生路，不应让政治斗争影响农民生活。国民党立委洪孟楷、国民党前发言人杨智伃等人也借此质疑，过去民进党籍地方首长亦曾赴大陆行销农产品，如今国民党籍县市长以视频推销台东农产却遭查处，显示当局所谓规范背后带有明显政治选择性。陆委会副主委梁文杰随后称，凤梨释迦是台湾人几乎不吃、完全仰赖大陆市场的农产品，该说法又引发另一波反弹。联合报报道称，YouTube频道"野电视94强"发起投票，超过2万人参与，其中92%不认同梁文杰说法。

第二起事件是新北先啬宫两岸共祭伏羲大典被政治化。6月21日，第十三届"海峡两岸共祭伏羲典礼"在台湾新北市三重先啬宫与甘肃天水同步举行，先啬宫董事长、国民党副主席李乾龙担任台湾会场主祭官。陆委会副主委梁文杰称，该活动"多年未变"，一直是"台办系统"活动，将持续关注是否违反相关规定。绿营人士则抓住甘肃主会场祭文出现"反独促统、民心所望"等表述，批评该活动是大陆对台统战叙事的一部分。李乾龙则回应称，此为文化民俗活动，台湾许多民间信仰和文化源流与大陆有关，追根溯源是中华民族传统美德。赖当局的反应和绿营舆论反而暴露出其对中华文化纽带在岛内延续的敏感和焦虑。

第三起事件是李立群吐槽台湾看不到免费世界杯转播，被陆委会引向统战的口水战。台湾演员李立群6月中旬在社交平台称，在台湾搜索不到世界杯足球赛免费转播。6月17日，国台办发言人陈斌华回应称，中央广播电视总台已取得本届世界杯在中国的独家全媒体权利并免费向全民提供，欢迎台湾同胞通过大陆网络、App观看赛事直播，或到大陆观赛。陆委会随后回应称，台湾爱尔达电视已取得台湾地区转播代理权，台湾球迷无须使用大陆网络或App，并批评国台办"闲事管太多"。联合早报6月18日报道指出，由于FIFA赛事版权费用较高，本届世界杯在台湾不再由免费电视频道完整播出，若观看完整赛事需通过付费平台订阅。这一生活化事件本身并非重大政治议题，仍被台当局解读为"统战"。

第四起事件是大陆演员张凌赫出席海峡论坛被称为"统战工具"。6月13日，张凌赫出席海峡论坛开幕式并发表演讲，表示文化力量能够连接两岸同胞的心，期待两岸影视有更多合作，也希望台湾同胞到大陆走一走看一看。联合报报道称，张凌赫在台湾有一定粉丝基础，其出席论坛引发现场关注；民进党立委王世坚随后称，中共会使用张凌赫作为"统战工具"，并称相关方式"完全没用"。陆委会方面则称，若其赴台申请合规且没有统战风险，将按规定审查。这一事件说明赖当局对大陆流行文化影响台湾青年群体的警惕，两岸青年通过影视、偶像和文化内容形成自然亲近感的空间正在成为其重点防范控制的对象。

# 二、岛内舆论反应

围绕统战，网民观点大体分化为以下几类。

**一是相当多网民反感当局将正常生计和政治挂钩，认为农产品销售本就不应被贴标签。** 这类评论的立场并不完全一致，有人倾向两岸交流，有人主张分散市场，但都认为农民收入、青年就业等现实利益不应被政治口号牺牲。Facebook网民刘诗涵称："真的很悲哀，现在连民间交流都要被贴红标签。"Facebook网民杨文正则直接表态："挺饶庆铃！帮农民找生路才是真正做实事。"Facebook网民林彦翔称："一味对抗只会把台湾推向战争边缘，支持两岸交流。"Facebook网民郑静宜的评论更为直接："连观光交流、青年就业都要管，真是不讲理。"在实际消费体验和转播成本上，X平台网民陈阿怪：“中华电信跟爱尔达吃相难看到，绑了一堆我看不到的频道、预设自动续费、强迫最低消费一季，看一场球成本要十几块。“X平台网民义德台仰称："别人才说了两句话，就被当成是统战工具，看来有些人是越来越没自信了。" 当局越是将管制范围扩及日常生活，越容易在基层激起反感。

**二是绿营支持者网民认同当局对大陆市场的警惕，主张分散销路、降低对大陆的依赖。** 此类声音在绿营支持者中较为常见，核心逻辑是把大陆市场等同于政治风险，认为高度依赖大陆市场会授人以柄，农渔业应该另寻出路。Facebook网民Chia-Ching Wang称："我们的释迦完全有能力外销到其他国家，只是要不要花心力去推销，而且台湾水果在国际市场也是有名的，完全依靠外销中国根本就是自找死路而已。"X平台网民Angel10222011也称："台东的选择，就看聪不聪明了。芒果可以进法国、日本市场，你凤梨却只能看中国脸色，真可悲。"不过，这类主张在事实层面遭到质疑。有Facebook网民直接拿数据反驳："凤梨释迦每年台湾本地销量大概也有六千公吨，然后民进党吹上天的欧盟芒果目前第一批累计销量五公吨而已。"

**三是陆委会副主委梁文杰"台湾人几乎不吃凤梨释迦"的言论成为舆论引爆点。**Yahoo新闻转载联合报6月21日报道称，YouTube频道"野电视94强"发起网络投票，超2万人参与，92%不认同梁文杰说法，相关留言包括"我吃，台东凤梨释迦很好吃""夏天常常买不到，在睁眼说瞎话什么""只要当了官，就跟一般百姓生活在两个维度"Facebook上同样有大量此类反馈，例如，网民Cathy Pan称："释迦我每次都一箱一箱买，怎么说台湾人'几乎不吃'，超好吃的，我们要吃好不好！不能依赖中国是对的，但就不能说台湾人'几乎'不吃……简直小看我们了！生气！"此事说明，民生议题一旦与民众日常经验相冲突，当局说法的可信度就会迅速崩塌，事后补救也难以挽回。

总体来看，绿营叙事在基本盘中仍有一定动员力，但在农民、球迷、青年粉丝和民俗团体等具体人群面前，管制的理由并不总能说服人。岛内舆论真正抵触的，并非某一个具体事件的处理，而是日常生活中的吃饭看球、祭祖追星被整体纳入政治审查的逻辑。赖当局越是把"统战"标签泛化使用，越容易在与民众日常经验发生冲突时丧失说服力。

# 三、风险研判及应对建议

**一是警惕赖当局把"反统战"扩展为阻断两岸交流的常态化工具。** 此前台当局以"资安风险"等理由对小红书等大陆社交平台实施限制，已切断了台湾青年接触大陆日常生活的便捷窗口；此次把农产品推销、伏羲祭典、世界杯转播、艺人交流等不同领域的活动一并纳入"统战"叙事，说明其管制范围正在从平台向具体的人、产品和场景延伸。台当局害怕台湾民众通过任何渠道了解真实的大陆、形成对大陆的好感与信任。后续需密切关注台当局是否继续以统战名义，扩大对大陆App与影视内容、演唱会与青年交流、旅游团与宗教民俗往来、地方农渔业采购的限制，把两岸之间尚存的交流通道逐一堵上。

**二是在对外传播中，避免只停留在概念正名层面，应更多着墨于岛内民众的切身感受。** 为"统战"正名、解释"大团结、大联合"的含义固然必要，但如果仅反复输出这一套表述，在岛内舆论场容易被理解为大陆在自说自话。岛内中间民众未必关心"统战"一词的理论内涵，但他们在意农产品销路、看球、追剧追星等日常生活。传播内容宜更多从这些具体话题切入，用岛内民众自己能感知的生活逻辑来反衬当局管制的不合理。同时需注意防止我方传播中过度使用刺激性、胜利式表达。此前岛内社交平台曾出现"因为张凌赫我不排斥统一""这就是民进党说的统战吗多来一点"等疑似反串言论，被绿营媒体用作统战的证据。后续涉台湾青年粉丝和社交平台的讨论，应避免提供此类可被截取利用的素材，保持表达的专业感和可信度。

**三是注意保护愿意参与两岸交流的台湾民众和团体，降低其岛内风险。** 赖当局制造的寒蝉效应之下，许多基层人士内心未必拒绝交流，但会担心被台当局查处、被打上政治标签。后续交流项目应减少参与者的不必要政治曝光；对农渔民、青年学生、民俗团体、文娱从业者等群体，可提供更具体的对接渠道；对在岛内受到舆论攻击的交流参与者，宜及时帮助澄清事实，减轻其岛内压力。同时应有意识地保存和放大岛内社交平台上那些支持正常交流、质疑当局管制的"温和原声"，来自岛内民众自身的声音说服力显然优于大陆媒体。
