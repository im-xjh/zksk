# 台湾常见媒体知识库

> 用途：供撰写涉台舆情月报、专报和素材检索时参考。  
> 口径说明：本文所列“政治倾向”是基于台湾媒体长期报道取向、岛内舆论常见认知和公开研究资料的概括，不等于每篇报道、每位记者或每档节目均持同一立场。正式报告中引用媒体时，应以具体报道事实为准，并避免把媒体解读直接写成事实。

## 一、台湾媒体生态总览

台湾媒体市场高度商业化、竞争激烈，政治立场分化明显。英国路透新闻研究所《Digital News Report 2024》台湾章节指出，台湾媒体由多家私人企业主导，竞争激烈且日益两极化，统“独”、两岸关系等议题经常在新闻和评论中呈现明显立场差异（Reuters Institute，2024年6月17日，https://reutersinstitute.politics.ox.ac.uk/digital-news-report/2024/taiwan）。《Digital News Report 2026》台湾章节进一步提到，台湾受众大量转向社交平台获取新闻，媒体也加强短视频和Threads等平台经营（Reuters Institute，2026年，https://reutersinstitute.politics.ox.ac.uk/digital-news-report/2026/taiwan）。

写作时可将台湾媒体粗分为四类：

1. 公共/官方色彩较强媒体：中央社、公视、央广等。
2. 泛绿或本土派媒体：自由时报、三立、民视、Newtalk、上报等。
3. 泛蓝或较偏蓝媒体：联合报系、TVBS、中时集团、中天、中视等。
4. 商业门户与综合平台：Yahoo奇摩、ETtoday、东森、风传媒、镜周刊等，立场较混合，但选题和标题常有流量导向。

## 三、主要媒体说明

### 1. 中央社

中央社是台湾最常用的基础事实源之一。它对台行政机构、立法机构、防务部门、陆委会、选务机构等消息跟进较快，时间、数字、职务和会议名称相对稳定。涉台报告中，可优先用中央社核验“发生了什么”。

使用时要注意，中央社的称谓和政治表述基本沿用台湾官方口径，如“总统”“国防部”“立法院”“中国”等。面向大陆官方受众写作时，应相应改写为“台湾地区领导人”“台防务部门”“台立法机构”“大陆”等。

### 2. 联合报系

联合报、联合新闻网、经济日报同属联合报系。联合报长期被视为偏蓝或中间偏蓝，传统报纸风格较强，常能看到国民党、工商界、地方政治、两岸务实交流等角度。经济日报偏财经和产业，适合核验半导体、股市、能源、外贸和产业政策。

使用联合报系材料时，建议区分新闻报道、社论、民意论坛和转载稿。新闻报道可用于事实核验；社论和民意论坛适合观察观点，不宜直接写成岛内整体舆论。

### 3. 自由时报系

自由时报、自由电子报、英文Taipei Times通常被视为泛绿、本土派媒体。维基百科条目也将自由时报描述为泛绿、倾向台湾独立立场的媒体，并将其与偏泛蓝的联合报作对照（Wikipedia，Liberty Times，https://en.wikipedia.org/wiki/Liberty_Times）。自由时报系在涉大陆、两岸、安全、选举议题上立场鲜明，常能反映绿营攻击点和本土派论述。

使用时适合观察民进党、绿营意见场和英文对外传播口径；但在大陆相关议题上，不宜直接采纳其定性，应与中央社、联合报、中时、官方发布进行交叉核验。

### 4. 中时集团

中国时报、中时新闻网、中天新闻、中视同属旺旺中时集团。该集团在岛内政治光谱中通常被视为泛蓝、反民进党，涉两岸议题上相对强调交流、反对“台独”，也常被绿营称为“亲中”。中天新闻台曾因执照问题被台湾主管机关撤照，后转向网络平台，YouTube传播力较强。

使用中时、中天材料时，可用于观察蓝营和反绿舆论，但政论节目情绪较强，正式报告中应优先引用其新闻报道而非节目口号。若用作事实来源，最好与中央社、联合报或其他媒体交叉核验。

### 5. 三立、民视、Newtalk

三立、民视、Newtalk是观察绿营舆论的重要来源。三立和民视电视政论节目立场较强，常围绕国民党、民众党、大陆议题进行攻击性解读。Newtalk则在网络传播和绿营意见场中较活跃。

这些媒体适合观察民进党如何包装议题、绿营意见账号如何扩散叙事，但不适合作为争议事件唯一事实来源。正式稿中可写“绿营媒体称”“部分绿营媒体将其解读为”，不要直接把其判断写成事实。

### 6. TVBS、东森、ETtoday

TVBS通常被视为偏蓝或中间偏蓝，新闻生产能力较强，民调和即时新闻常被引用。东森、ETtoday商业化特征强，社会、娱乐、突发和生活新闻更新快，政治立场相对议题化和流量化。

这些媒体适合补充事件热度、民调和社会反应。使用时应检查标题是否夸张，避免把网络化用语带入正式报告。

### 7. 公视

公视属于公共媒体，商业化压力相对较低，灾害、公共安全、社会治理、劳工、医疗、弱势群体等议题报道较稳。它在政治立场上通常比商业政论节目克制，但公共电视内部的专题、评论和节目仍可能有自由派或本土视角。

撰写公共安全、灾害、金融诈骗、社会治理事件时，公视是较好的基础来源之一。

### 8. Yahoo奇摩新闻

Yahoo奇摩新闻是新闻聚合平台，常转载中央社、联合报、TVBS、三立、民视等内容。它的价值在于便于检索和观察传播热度，但不能把“Yahoo新闻”当作原创媒体。

报告中如引用Yahoo页面，应写成“Yahoo新闻转载中央社报道称”或“Yahoo新闻转载某媒体报道称”，并在句末保留链接。

## 四、按政治倾向快速分组

### 泛绿/本土派色彩较强

自由时报、Taipei Times、三立、民视、Newtalk、上报、部分镜周刊政治报道。

常见特点：

1. 涉大陆议题警惕性高，常使用“统战”“认知作战”“渗透”等框架。
2. 对民进党政策较少根本性否定，但会在具体治理事件上批评。
3. 对国民党、民众党和两岸交流议题常持较强质疑态度。

### 泛蓝或偏蓝

联合报、中时、中国时报、中天、中视、TVBS部分报道和政论。

常见特点：

1. 更关注民进党施政缺失、财政纪律、能源、治安和两岸紧张风险。
2. 对两岸交流、地方县市赴陆、农渔产品销售等议题较容易呈现务实角度。
3. 对美国对台军售、防务预算、民进党“抗中保台”叙事常有批评。

### 相对公共/基础事实源

中央社、公视、部分经济日报报道。

常见特点：

1. 适合核验时间、数字、官方说法。
2. 政治定性相对少，但称谓沿用台湾官方口径。
3. 不代表完全中立，仍需注意议题选择和引用对象。

### 商业流量和综合平台

ETtoday、东森、Yahoo奇摩、NOWnews、壹苹新闻网、风传媒、镜周刊。

常见特点：

1. 更新快、标题抓人，适合发现事件。
2. 政治立场不总是固定，常与节目、作者、流量需求有关。
3. 爆料类、标题党、社群热议类内容需谨慎核验。

## 五、写涉台报告时的媒体使用建议

### 1. 事实核验优先级

建议优先顺序：

1. 官方文件或主管部门公告。
2. 中央社、公视、联合报等相对稳定来源。
3. 不同政治倾向媒体交叉验证，如自由时报与联合报、中时对照。
4. 商业门户和社交平台材料只作补充，不作唯一事实来源。

### 2. 舆论判断不要只看单一阵营

涉台议题常出现蓝绿媒体对同一事件完全不同的解读。比如：

1. 蓝营媒体可能强调民进党当局阻断交流、脱离民生。
2. 绿营媒体可能强调大陆“统战”、安全风险和“认知作战”。
3. 公共媒体可能聚焦程序、公共利益和政策执行。

正式报告应写“蓝营舆论关注……”“绿营媒体则将其解读为……”，而不是直接写“岛内舆论普遍认为”。

### 3. 台湾官方称谓需按大陆官方口径改写

常见改写如下：

| 台媒常用词 | 大陆官方报告建议写法 |
| ---- | ---- |
| 总统 | 台湾地区领导人，或直接写赖清德 |
| 行政院 | 台行政机构 |
| 立法院 | 台立法机构 |
| 国防部 | 台防务部门 |
| 外交部 | 台外事部门 |
| 陆委会 | 台陆委会 |
| 国安局 | 台安全部门或台情报部门 |
| 中国 | 大陆，或中国大陆 |
| 我国 | 台湾方面，台当局 |
| 中国威胁 | 所谓“大陆威胁”或台媒称“大陆威胁” |
| 总统大选 | 台湾地区领导人选举 |
| 立委 | 台民意代表 |

### 4. 链接标注规范

正文中引用媒体来源时，建议统一写成：

“6月10日，据联合报报道，……（联合报，2026年6月10日报道，链接）。”

如果是转载，写成：

“Yahoo新闻转载中央社报道称……（Yahoo新闻转载中央社，2026年6月22日报道，链接）。”

如果是评论或社论，写成：

“经济日报社论指出……（经济日报社论，2026年6月10日，链接）。”

### 5. 如何判断媒体观点是否可用

可用作事实：

1. 时间、地点、会议、投票、预算数字、伤亡人数。
2. 当事方直接引语。
3. 官方公告、司法文书、选务数据。

可用作舆论：

1. 社论、评论、政论节目观点。
2. 蓝绿阵营对同一事件的不同解读。
3. 专家学者分析。

不宜直接使用：

1. 没有来源的“网传”。
2. 单一政论节目中的情绪化说法。
3. 标题中的夸张词，如“炸锅”“翻车”“崩溃”“惨了”。
4. 未经核验的社媒截图。

## 六、常见组合用法

### 两岸交流议题

建议组合：

1. 中央社核事实。
2. 联合报或中时看蓝营、地方民生角度。
3. 自由时报、三立、Newtalk看绿营安全化叙事。
4. 国台办、新华社、人民日报海外版看大陆官方口径。

### 选举议题

建议组合：

1. 中央社核提名、投票、党务程序。
2. 联合报、TVBS看民调和蓝白合作。
3. 自由时报、三立、民视看绿营攻防。
4. 中时、中天看反绿和蓝营基层动员。

### 军事安全议题

建议组合：

1. 中央社核台防务部门说法。
2. 联合报、TVBS看军方消息和立法机构攻防。
3. 自由时报看绿营安全叙事。
4. 大陆官方媒体和国防部、国台办发言核大陆立场。

### 民生经济和产业议题

建议组合：

1. 经济日报、中央社核数据。
2. 联合报、工商时报看产业和工商界反应。
3. 公视看公共利益和民众影响。
4. 自由时报、三立看绿营政策包装。
