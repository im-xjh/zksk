# 2026年6-7月台湾岛内热点事件搜集SOP

## 一、定位

本SOP用于搜集2026年6月、7月台湾岛内热点事件，目标不是汇编所有台湾新闻，而是筛出适合进入“岛内热点事件/月度研判”的案例。参考《4月岛内热点+5月研判.md》的口径，优先关注能够反映岛内政治走向、两岸关系变化、选举态势、军安风险、民生经济压力、公共安全和社会治理争议的事件。

单条事件进入素材库前，至少要回答三个问题：

1. 这件事是否已经发生，关键事实能否核验。
2. 它是否引发岛内媒体、政治人物、专家或社交平台持续讨论。
3. 它是否能指向后续风险、政策变化、选举攻防或两岸议题变化。

若只能说明“发生了一件事”，但没有舆论焦点和后续关注价值，原则上不纳入月报主条目。

## 二、核心筛选标准

### 1. 优先纳入的事件

符合以下任一条件，优先进入候选清单：

1. 涉及两岸关系、两岸交流、陆委会、国台办、惠台措施、陆客赴台、航点恢复、金马离岛通水通电通桥、农渔产品入陆、文娱体育交流等。
2. 涉及岛内政治主线，包括赖清德当局施政争议、蓝绿白攻防、弹劾或罢免、立法机构冲突、政党合作、2026“九合一”选举布局、2028人选讨论等。
3. 涉及美国、日本、菲律宾等外部力量与台湾议题的联动，尤其是军售、军援、防务预算、议员访台、涉台法案、台海表态和美台军事合作。
4. 涉及台军演训、全民防卫动员、防空演习、汉光演习、城镇韧性演习、后备动员、民防训练，以及岛内舆论对“战争准备”“防务预算挤压民生”的反应。
5. 涉及能源、电价、物价、股市、台积电、半导体供应链、产业外移、就业和薪资等民生经济议题，且能体现岛内结构性压力或社会感受落差。
6. 涉及灾害、公共安全和基础设施风险，如地震、台风、停电、缺水、交通事故、重大工安事故、食品安全、医疗资源等，并有官方处置或舆论追问。
7. 涉及“国安化”“统战化”“认知作战化”争议，即岛内当局或绿营将普通交流、文化、体育、商业、平台使用等议题上升为安全风险，引发反弹。
8. 涉及重要法规、行政解释、候选资格、户籍身份、陆配权益、入境审查、平台封禁、媒体管制等制度性变化。
9. 涉及民调、社会心态和身份认同变化，特别是两岸谈判、和平交流、统一/独立、政党支持度、县市长选情等有明确样本和发布机构的材料。

### 2. 可纳入但需降级处理的事件

以下事件可以进入候选库，但通常不单独作为重点，除非出现政治化、群体性或持续发酵：

1. 单一地方民生投诉，如道路、噪音、社区纠纷、单点消费争议。
2. 单一名人或艺人争议，除非与两岸交流、政治表态、文化封锁、青年文娱交流、平台审查有关。
3. 单一企业经营或商业纠纷，除非涉及台积电、关键技术、产业安全、劳工群体、物价民生或两岸供应链。
4. 单一体育赛事，除非牵涉大陆选手入境、赛事政治化、转播权、两岸交流或岛内当局安全审查。
5. 网络平台热梗、短期情绪事件，除非已被媒体、政治人物或主管部门接住，形成公共议题。

### 3. 通常不写的事件

以下内容原则上不纳入月报主条目：

1. 纯娱乐八卦、明星恋情、综艺节目争议、粉丝互撕。
2. 与公共议题无关的影视剧宣发、演唱会、商业代言、网红流量事件。
3. 单纯社会奇闻、猎奇案件、低公共性的治安新闻。
4. 无法核验来源、只有匿名爆料或单一社媒截图支撑的事件。
5. 旧闻翻炒，除非在6月或7月出现新的制度动作、官方回应、投票节点、司法结果或舆论再发酵。
6. 只有大陆媒体单方面报道，岛内媒体、官方或公开社交平台没有可核验反应的事件。

## 三、领域覆盖口径

### 1. 两岸与对外关系

重点看两类变化：一是大陆惠台、交流恢复、民生便利措施在岛内的反应；二是赖当局或绿营如何将交流议题安全化、统战化。美国、日本、菲律宾等外部因素进入报告时，要说明它们如何影响岛内防务预算、选举攻防、民意和台海风险，不宜只写外交新闻本身。

候选关键词：

- 国台办、陆委会、两岸交流、陆客赴台、航点、金门、马祖、通电、通水、农渔产品、影视节目、青年交流、海峡论坛
- 美国对台军售、军援、FMF、防务预算、议员访台、涉台法案
- 日本、菲律宾、南海、台海、联合军演、印太司令部

### 2. 岛内政治与选举

重点看蓝绿白围绕年底“九合一”选举的议题设置、候选人提名、蓝白合作、赖清德施政争议和民进党“抗中保台”叙事的调整。单纯人事传闻不作为重点，除非已影响提名、民调或政党攻防。

候选关键词：

- 九合一、县市长、蓝白合、国民党、民众党、民进党、赖清德、韩国瑜、郑丽文、黄国昌、卢秀燕、蒋万安
- 弹劾、罢免、立法院、财政收支划分法、预算审议、民调

### 3. 军事安全与社会动员

重点看防务预算、军售、台军演训、民防动员和普通民众生活之间的张力。写作时不要只罗列演习科目，要看是否出现人车管制、警报测试、校园或社区动员、企业配合、民众不满等具体影响。

候选关键词：

- 汉光演习、城镇韧性、全民防卫动员、万安演习、防空演习、后备军人、民防、台军、海巡
- 防务预算、军购、导弹、无人机、美国军援

### 4. 民生经济与产业

重点看股市上涨与“体感贫穷”、物价、电价、能源供应、产业结构之间的落差。台积电、半导体、关键技术和供应链事件优先级较高；一般消费新闻只有在牵涉群体性民生压力时才纳入。

候选关键词：

- 台股、台积电、半导体、泄密、供应链、出口、就业、薪资
- 电价、缺电、台电、中油、天然气、油价、物价、房价、通胀、体感贫穷

### 5. 灾害与公共安全

重点看灾害事件是否具有预警、处置、基础设施、民众信任等议题。单次小规模事故不宜放大，除非出现伤亡、全岛影响、官方处置争议或专家预警。

候选关键词：

- 地震、花莲、台风、豪雨、停电、停水、交通事故、工安、食品安全、医疗、消防

### 6. 社会治理与身份制度

重点看制度解释和身份审查如何影响陆配、两岸婚姻、候选资格、入境、社群平台使用和公共表达。此类事件通常不一定热度最高，但容易体现赖当局政策取向，适合进入月报。

候选关键词：

- 陆配、户籍、两岸条例、候选资格、入境审查、居留、除籍、国安、认知作战、统战、平台封禁

### 7. 文化、体育、青年与娱乐

此领域不是排除项，但必须有公共议题转化。纯娱乐不写；若事件触及两岸文娱交流、青年接触大陆内容、赛事转播、艺人被政治审查、大陆选手入境、文化祭典被贴“统战”标签，则可纳入。

判断问题：

1. 是否从娱乐或体育事件延伸到两岸交流、身份认同、平台审查或政治表态。
2. 是否有岛内媒体、政治人物、主管部门或意见账号介入。
3. 是否出现普通民众生活不便，如赛事付费、平台限制、活动取消、入境卡关。

## 四、优先级判定

### A类：主条目

符合以下特征之一，可作为月报重点条目：

1. 涉及两岸、选举、军安、对外关系等主线。
2. 有明确时间节点和后续发展，如投票、审议、演习、判决、政策实施。
3. 至少有两类来源可互相印证，例如官方文件加台媒报道，或台媒报道加政治人物回应。
4. 舆论焦点清楚，能写出“争议落点”和“后续关注点”。

### B类：候选条目

具备一定热度或代表性，但后续影响仍待观察。可先放入素材库，若出现官方回应、政党攻防、社媒扩散或新节点，再升级。

### C类：背景材料

适合作为某个重点条目的背景，不单独成条。例如单条民调、单篇评论、某位政治人物单次表态、地方小范围争议。

### D类：剔除

事实不稳、来源单薄、公共性不足、纯娱乐、旧闻重复或无法形成研判的问题，标为剔除并说明原因。

## 五、6月和7月的重点观察方向

### 6月回溯重点

6月搜集时，优先沿着5月研判和4月热点的后续线索回看：

1. 赖清德弹劾案投票后续及蓝白政治造势效果。
2. 特别防务预算审议、删减、重提或美国施压。
3. 美国对台军售、军援、涉台法案和岛内反应。
4. “九合一”选举提名、蓝白合民调、地方战区变化。
5. 大陆惠台措施落地，包括航点、陆客、农渔产品、影视节目、金马民生合作。
6. 城镇韧性、全民防卫动员、汉光演习前期安排和民众反应。
7. 能源、电价、物价、台股、台积电及产业安全事件。
8. 陆配、户籍、入境、平台使用和普通交流被安全化的个案。

### 7月滚动重点

7月搜集时，重点看现实触发点：

1. 夏季用电高峰、台风季、地震和公共安全事件。
2. 汉光演习、防空演习、民防动员、社区和校园配合。
3. 年底选举提名定局、蓝白合机制运行、地方候选人攻防。
4. 防务预算、军购和美国涉台动作是否进入新审议节点。
5. 暑期两岸青年、文旅、赛事、文娱交流是否被贴“统战”标签。
6. 陆客、航点、金马民生合作等惠台措施是否出现执行落差或政治阻力。
7. 民调变化，尤其是赖清德施政满意度、政党支持度、两岸谈判和和平交流态度。

## 六、检索与核验流程

### 1. 先建候选清单

每轮检索先按领域列候选事件，不急于写成报告。候选事件必须记录时间、主体、事件一句话、来源链接、初步优先级。

### 2. 再核关键事实

优先核验以下信息：

1. 时间、地点、人物职务和机构名称。
2. 投票结果、预算金额、民调样本、伤亡人数、地震规模、股市点位等数字。
3. 政策是否已经发布、通过、执行，还是仍在提案、审议或媒体放风阶段。
4. 舆论反应是否来自媒体报道、政治人物表态、专家评论还是网民讨论，不要混写。

### 3. 来源优先级

优先使用可回链来源，正文引用时按“某媒体某月某日发文/报道称”标明，并在句末保留链接。

1. 官方来源：台湾行政、立法、防务、陆委会、气象、能源、选务等部门；大陆国台办、海关、文旅、交通等部门；美国国会、国务院、国防部等公开文件。
2. 岛内主流媒体：中央社、联合新闻网、中时新闻网、自由时报、TVBS、民视、ETtoday、Yahoo新闻等。
3. 国际媒体和外部机构：Reuters、AP、Bloomberg、VOA、Nikkei等，用于涉美、涉外、产业和市场事件。
4. 社交平台：X、Reddit、Facebook、Instagram、Threads、YouTube等只作为舆论样本，必须说明可见性边界，不得把少量评论写成整体民意。

### 4. 社媒材料处理

检索阶段可以按平台整理，写作阶段必须按观点类型归并。不要写成“Facebook认为、X认为、Reddit认为”。更稳的写法是：

1. 支持两岸交流、反对泛化“统战”的声音。
2. 支持当局审查、强调政治安全风险的声音。
3. 从民生成本、观看便利、农产品销售、青年交流角度批评过度政治化的声音。
4. 从版权、活动程序、市场秩序等角度提出技术性讨论的声音。

若某平台没有有效样本，应写“未检索到直接相关集中讨论”或“不纳入研判”，不要用无关材料补数。

## 八、单条事件成稿判断模板

一条事件若要进入月报正文，应能写出以下四项：

1. 事件事实：何时、谁、做了什么，引用哪些可核验来源。
2. 舆论焦点：讨论集中在哪些问题，哪些群体或阵营最敏感。
3. 研判提示：风险来自哪里，什么条件会让它继续发酵。
4. 后续关注：接下来要看哪个投票、审议、演习、政策实施、民调或官方回应。

若只能写出第一项，通常不作为主条目。

## 九、写作边界

1. 不把媒体解读写成事实。
2. 不把网民观点写成岛内整体民意。
3. 不用“全网炸锅”“翻车”“塌房”等网络化词语。
4. 不把所有民生、娱乐、体育事件都强行上升为政治议题。
5. 不跨事件硬串。不同事件可以服务于整体态势判断，但单条分析只围绕本事件展开。
6. 不写没有触发点的空泛研判。每条至少指出一个后续节点或传播风险。
7. 不保留修改痕迹，不写“不是A而是B”式自造靶子，除非A确实是舆论场真实存在的说法。

## 十、最终筛选清单

每次完成一轮搜集后，按以下格式输出阶段性结果：

1. A类主条目：建议进入月报，按重要性排序。
2. B类候选：继续观察，注明升级条件。
3. C类背景：可作为主条目背景或研判支撑。
4. D类剔除：说明剔除原因，避免重复检索。

最终月报宜控制在10至15个重点条目左右。若6月或7月事件密集，可将同一主线合并成一条，例如“防务预算与美国军售压力”“九合一选举前哨战及蓝白合作”“两岸交流措施落地与岛内安全化反应”，避免把同一链条拆成过多碎片。
